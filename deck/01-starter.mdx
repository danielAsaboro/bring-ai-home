Slide tools make it easy to format a slide before you know what it argues. The hard part of a talk is the argument: the claim, the evidence that backs it, the order, and how long each beat takes.

Deck treats an argument as a playable set of cards. Cards are claims or evidence. Rounds are the narrative sections. Playing the deck is the match. This chapter builds the whole non-AI product first, so every later chapter adds local AI to an app that already does its job by hand.

**Source checkpoint:** `fbc58e0` · **Starting checkpoint:** `3b21931`

## What you change

| File | Responsibility |
| --- | --- |
| `src/features/deck/deck.ts` | The card, round, and deck model with pure operations: add, edit, discard, reorder inside a round, reorder rounds, play order, and pacing |
| `src/features/deck/sample-library.ts` | Two fictional decks: an eight-card Lumen Kettle launch and a short library-hours pitch |
| `src/features/deck/storage.ts` | The one storage adapter. It wraps `localStorage` and falls back to the sample library |
| `src/features/deck/DeckApp.tsx` | Deck list, rounds with cards, card editor, pacing bars, **Play the match**, and **Reset demo data** |
| `src/app/page.tsx`, `src/app/layout.tsx` | Render Deck and name the page |
| `vitest.setup.ts` | Clean up rendered components between tests |

Every company, product, and number in the sample decks is invented.

## Build and observe

### 1. Get the code

```bash
git clone https://github.com/danielAsaboro/bring-ai-home
cd bring-ai-home
git checkout 3b21931
npm install
```

### 2. Run it

```bash
npm run dev
```

Open http://localhost:3000. Deck opens on **Lumen Kettle launch**: three rounds (The problem, The product, The ask) and eight cards. The pacing view shows 5:35 in total, with The product round the longest at 2:40.

### 3. Do the manual job once

1. In **The ask**, type `Pilot results date` into **New card** and press **Add**.
2. Press the left arrow on **The ask** to move the round earlier. The pacing bars reorder with it.
3. Click **Mornings are rushed**, change its title in the editor, and press **Save card**.
4. Press **Play the match**. Use **Next** or the arrow keys; **Escape** leaves the match.
5. Reload. Your changes are still there. Press **Reset demo data** to return to the sample decks.

### 4. Read the boundary

`storage.ts` is the only code that touches `localStorage`. It catches blocked or corrupt storage, so a private window still opens. Tests pass `createMemoryStore()` instead.

`moveCard` swaps a card only with its neighbour in the same round. Moving a card to another round is an explicit edit in the card editor, so a reorder can never silently change the narrative.

"use client";

import { useEffect, useState, useSyncExternalStore, type FormEvent } from "react";

import {
  activeDeck,
  addCard,
  addRound,
  createDeck,
  formatSeconds,
  moveCard,
  moveRound,
  pacing,
  playOrder,
  removeCard,
  updateCard,
  type Card,
  type CardKind,
  type Deck,
  type Library,
  type Treatment,
} from "./deck";
import { createLocalStore, type LibraryStore } from "./storage";

const noopSubscribe = () => () => undefined;

export function DeckApp({ store }: { store?: LibraryStore }) {
  const mounted = useSyncExternalStore(noopSubscribe, () => true, () => false);
  if (!mounted) return <p className="p-6">Shuffling the deck…</p>;
  return <DeckView store={store ?? createLocalStore()} />;
}

const field = "rounded border border-slate-400 bg-white px-2 py-1 text-sm text-slate-900";
const button = "rounded bg-indigo-800 px-3 py-1 text-sm font-medium text-white hover:bg-indigo-900";
const ghost = "rounded border border-slate-400 px-2 py-0.5 text-xs hover:bg-slate-100 disabled:opacity-40";

function DeckView({ store }: { store: LibraryStore }) {
  const [library, setLibrary] = useState<Library>(() => store.load());
  const [selectedId, setSelectedId] = useState<string | null>(null);
  const [presenting, setPresenting] = useState(false);
  const deck = activeDeck(library);
  const selected = deck.cards.find((c) => c.id === selectedId) ?? null;

  function commit(next: Library) {
    setLibrary(next);
    store.save(next);
  }

  if (presenting) return <Match deck={deck} onExit={() => setPresenting(false)} />;

  return (
    <div className="mx-auto grid max-w-6xl gap-6 p-4 md:grid-cols-[220px_1fr]">
      <aside className="space-y-4">
        <h1 className="text-2xl font-bold">Deck</h1>
        <nav aria-label="Decks">
          <ul className="space-y-1">
            {library.decks.map((d) => (
              <li key={d.id}>
                <button
                  className={`w-full rounded px-2 py-1 text-left text-sm ${d.id === deck.id ? "bg-indigo-100 font-semibold" : "hover:bg-slate-100"}`}
                  aria-current={d.id === deck.id ? "true" : undefined}
                  onClick={() => {
                    commit({ ...library, activeDeckId: d.id });
                    setSelectedId(null);
                  }}
                >
                  {d.title}
                </button>
              </li>
            ))}
          </ul>
        </nav>
        <NewDeckForm onCreate={(title, audience) => commit(createDeck(library, title, audience))} />
        <button className={ghost} onClick={() => commit(store.reset())}>
          Reset demo data
        </button>
      </aside>

      <section className="space-y-4">
        <header className="flex flex-wrap items-end justify-between gap-2">
          <div>
            <h2 className="text-xl font-semibold">{deck.title}</h2>
            <p className="text-sm text-slate-600">Audience: {deck.audience || "not set"}</p>
          </div>
          <button className={button} onClick={() => setPresenting(true)} disabled={deck.cards.length === 0}>
            Play the match
          </button>
        </header>

        <PacingView deck={deck} />

        <div className="grid gap-3 lg:grid-cols-3">
          {deck.rounds.map((round, i) => (
            <section key={round.id} aria-label={`Round: ${round.title}`} className="rounded-lg border border-slate-300 bg-white p-3">
              <div className="mb-2 flex items-center justify-between gap-1">
                <h3 className="font-semibold">
                  Round {i + 1}: {round.title}
                </h3>
                <span className="flex gap-1">
                  <button className={ghost} aria-label={`Move ${round.title} earlier`} disabled={i === 0} onClick={() => commit(moveRound(library, deck.id, round.id, -1))}>
                    ←
                  </button>
                  <button className={ghost} aria-label={`Move ${round.title} later`} disabled={i === deck.rounds.length - 1} onClick={() => commit(moveRound(library, deck.id, round.id, 1))}>
                    →
                  </button>
                </span>
              </div>
              <ol className="space-y-2">
                {deck.cards
                  .filter((c) => c.roundId === round.id)
                  .map((card, j, roundCards) => (
                    <li key={card.id}>
                      <CardTile
                        card={card}
                        selected={card.id === selectedId}
                        onSelect={() => setSelectedId(card.id)}
                        onUp={j > 0 ? () => commit(moveCard(library, deck.id, card.id, -1)) : undefined}
                        onDown={j < roundCards.length - 1 ? () => commit(moveCard(library, deck.id, card.id, 1)) : undefined}
                      />
                    </li>
                  ))}
              </ol>
              <AddCardForm
                roundTitle={round.title}
                onAdd={(title, kind) =>
                  commit(addCard(library, deck.id, { kind, title, body: "", treatment: "headline", seconds: 30, roundId: round.id }))
                }
              />
            </section>
          ))}
        </div>
        <AddRoundForm onAdd={(title) => commit(addRound(library, deck.id, title))} />

        {selected && (
          <CardEditor
            key={selected.id}
            card={selected}
            deck={deck}
            onSave={(patch) => commit(updateCard(library, deck.id, selected.id, patch))}
            onRemove={() => {
              commit(removeCard(library, deck.id, selected.id));
              setSelectedId(null);
            }}
          />
        )}
      </section>
    </div>
  );
}

function CardTile({ card, selected, onSelect, onUp, onDown }: { card: Card; selected: boolean; onSelect: () => void; onUp?: () => void; onDown?: () => void }) {
  const tone = card.kind === "claim" ? "border-indigo-600" : "border-amber-600";
  return (
    <article className={`rounded border-l-4 ${tone} bg-slate-50 p-2 ${selected ? "ring-2 ring-indigo-400" : ""}`}>
      <button className="w-full text-left" onClick={onSelect}>
        <span className="text-xs uppercase tracking-wide text-slate-500">
          {card.kind} · {card.treatment} · {formatSeconds(card.seconds)}
        </span>
        <span className="block font-medium">{card.title}</span>
      </button>
      <span className="mt-1 flex gap-1">
        <button className={ghost} aria-label={`Move ${card.title} up`} disabled={!onUp} onClick={onUp}>
          ↑
        </button>
        <button className={ghost} aria-label={`Move ${card.title} down`} disabled={!onDown} onClick={onDown}>
          ↓
        </button>
      </span>
    </article>
  );
}

function CardEditor({ card, deck, onSave, onRemove }: { card: Card; deck: Deck; onSave: (patch: Partial<Card>) => void; onRemove: () => void }) {
  const [draft, setDraft] = useState(card);
  function submit(event: FormEvent) {
    event.preventDefault();
    onSave({ title: draft.title, body: draft.body, kind: draft.kind, treatment: draft.treatment, seconds: draft.seconds, roundId: draft.roundId, source: draft.source });
  }
  return (
    <form aria-label="Edit card" onSubmit={submit} className="grid gap-2 rounded-lg border border-slate-300 bg-white p-3 md:grid-cols-2">
      <label className="grid text-sm">
        Title
        <input className={field} value={draft.title} onChange={(e) => setDraft({ ...draft, title: e.target.value })} />
      </label>
      <label className="grid text-sm">
        Source
        <input className={field} value={draft.source ?? ""} onChange={(e) => setDraft({ ...draft, source: e.target.value || undefined })} />
      </label>
      <label className="grid text-sm md:col-span-2">
        Body
        <textarea className={field} rows={3} value={draft.body} onChange={(e) => setDraft({ ...draft, body: e.target.value })} />
      </label>
      <label className="grid text-sm">
        Kind
        <select className={field} value={draft.kind} onChange={(e) => setDraft({ ...draft, kind: e.target.value as CardKind })}>
          <option value="claim">claim</option>
          <option value="evidence">evidence</option>
        </select>
      </label>
      <label className="grid text-sm">
        Treatment
        <select className={field} value={draft.treatment} onChange={(e) => setDraft({ ...draft, treatment: e.target.value as Treatment })}>
          <option value="headline">headline</option>
          <option value="quiet">quiet</option>
          <option value="data">data</option>
        </select>
      </label>
      <label className="grid text-sm">
        Seconds
        <input className={field} type="number" min={5} max={600} value={draft.seconds} onChange={(e) => setDraft({ ...draft, seconds: Number(e.target.value) })} />
      </label>
      <label className="grid text-sm">
        Round
        <select className={field} value={draft.roundId} onChange={(e) => setDraft({ ...draft, roundId: e.target.value })}>
          {deck.rounds.map((r) => (
            <option key={r.id} value={r.id}>
              {r.title}
            </option>
          ))}
        </select>
      </label>
      <span className="flex gap-2 md:col-span-2">
        <button className={button} type="submit">
          Save card
        </button>
        <button className={ghost} type="button" onClick={onRemove}>
          Discard card
        </button>
      </span>
    </form>
  );
}

function PacingView({ deck }: { deck: Deck }) {
  const { total, rounds } = pacing(deck);
  return (
    <section aria-label="Pacing" className="rounded-lg border border-slate-300 bg-white p-3">
      <h3 className="text-sm font-semibold">Pacing · {formatSeconds(total)} total</h3>
      <ul className="mt-2 space-y-1">
        {rounds.map((r) => (
          <li key={r.roundId} className="grid grid-cols-[8rem_1fr_4rem] items-center gap-2 text-sm">
            <span className="truncate">{r.title}</span>
            <span className="h-2 rounded bg-slate-200">
              <span className="block h-2 rounded bg-indigo-600" style={{ width: `${Math.round(r.share * 100)}%` }} />
            </span>
            <span>{formatSeconds(r.seconds)}</span>
          </li>
        ))}
      </ul>
    </section>
  );
}

function Match({ deck, onExit }: { deck: Deck; onExit: () => void }) {
  const cards = playOrder(deck);
  const [index, setIndex] = useState(0);
  const card = cards[Math.min(index, cards.length - 1)];
  const round = deck.rounds.find((r) => r.id === card?.roundId);

  useEffect(() => {
    function onKey(event: KeyboardEvent) {
      if (event.key === "ArrowRight") setIndex((i) => Math.min(i + 1, cards.length - 1));
      if (event.key === "ArrowLeft") setIndex((i) => Math.max(i - 1, 0));
      if (event.key === "Escape") onExit();
    }
    window.addEventListener("keydown", onKey);
    return () => window.removeEventListener("keydown", onKey);
  }, [cards.length, onExit]);

  if (!card) return null;
  return (
    <section aria-label="Presentation" className="flex min-h-screen flex-col items-center justify-center gap-6 bg-slate-900 p-8 text-white">
      <p className="text-sm uppercase tracking-widest text-slate-400">
        {round?.title} · card {index + 1} of {cards.length}
      </p>
      <h2 className={card.treatment === "headline" ? "text-5xl font-bold" : "text-3xl"}>{card.title}</h2>
      <p className="max-w-2xl text-center text-xl text-slate-200">{card.body}</p>
      {card.source && <p className="text-sm text-slate-400">Source: {card.source}</p>}
      <div className="flex gap-3">
        <button className={button} onClick={() => setIndex((i) => Math.max(i - 1, 0))} disabled={index === 0}>
          Previous
        </button>
        <button className={button} onClick={() => setIndex((i) => Math.min(i + 1, cards.length - 1))} disabled={index >= cards.length - 1}>
          Next
        </button>
        <button className={button} onClick={onExit}>
          Leave the match
        </button>
      </div>
    </section>
  );
}

function AddCardForm({ roundTitle, onAdd }: { roundTitle: string; onAdd: (title: string, kind: CardKind) => void }) {

import { describe, expect, it } from "vitest";

import { addCard, clampSeconds, moveCard, moveRound, pacing, playOrder, updateCard } from "./deck";
import { sampleLibrary } from "./sample-library";

const deckId = "deck-kettle";
const kettle = () => sampleLibrary.decks[0];

describe("deck operations", () => {
  it("plays cards in round order, then card order", () => {
    const moved = moveRound(sampleLibrary, deckId, "r-ask", -1);
    const order = playOrder(moved.decks[0]).map((c) => c.id);
    expect(order).toEqual(["c-1", "c-2", "c-7", "c-8", "c-3", "c-4", "c-5", "c-6"]);
    expect(playOrder(kettle()).map((c) => c.id)).toEqual(["c-1", "c-2", "c-3", "c-4", "c-5", "c-6", "c-7", "c-8"]);
  });

  it("reorders a card only inside its round", () => {
    const up = moveCard(sampleLibrary, deckId, "c-4", -1);
    expect(playOrder(up.decks[0]).map((c) => c.id).slice(2, 4)).toEqual(["c-4", "c-3"]);
    const edge = moveCard(sampleLibrary, deckId, "c-3", -1);
    expect(edge.decks[0].cards).toEqual(kettle().cards);
  });

  it("measures pacing per round", () => {
    const { total, rounds } = pacing(kettle());
    expect(total).toBe(335);
    expect(rounds.map((r) => r.seconds)).toEqual([90, 160, 85]);
  });

  it("clamps card timing and leaves the input library unchanged", () => {
    const next = addCard(sampleLibrary, deckId, { kind: "claim", title: "x", body: "", treatment: "quiet", seconds: 9999, roundId: "r-ask" });
    expect(next.decks[0].cards.at(-1)?.seconds).toBe(600);
    expect(kettle().cards).toHaveLength(8);
    expect(clampSeconds(Number.NaN)).toBe(30);
    expect(updateCard(sampleLibrary, deckId, "c-1", { seconds: 1 }).decks[0].cards[0].seconds).toBe(5);
  });
});

// Deck's product model. Every operation is pure: it takes a library and
// returns a new one, so the UI never edits state in place.

export type CardKind = "claim" | "evidence";
export type Treatment = "headline" | "quiet" | "data";

export type Card = {
  id: string;
  kind: CardKind;
  title: string;
  body: string;
  treatment: Treatment;
  seconds: number;
  roundId: string;
  source?: string;
};

export type Round = { id: string; title: string };

export type Deck = {
  id: string;
  title: string;
  audience: string;
  rounds: Round[];
  cards: Card[];
};

export type Library = { decks: Deck[]; activeDeckId: string };

let counter = 0;
export function newId(prefix: string): string {
  counter += 1;
  return `${prefix}-${Date.now().toString(36)}-${counter}`;
}

export function activeDeck(library: Library): Deck {
  return library.decks.find((d) => d.id === library.activeDeckId) ?? library.decks[0];
}

function updateDeck(library: Library, deckId: string, change: (deck: Deck) => Deck): Library {
  return { ...library, decks: library.decks.map((d) => (d.id === deckId ? change(d) : d)) };
}

export function createDeck(library: Library, title: string, audience: string): Library {
  const roundId = newId("round");
  const deck: Deck = {
    id: newId("deck"),
    title: title.trim() || "Untitled deck",
    audience: audience.trim(),
    rounds: [{ id: roundId, title: "Opening" }],
    cards: [],
  };
  return { decks: [...library.decks, deck], activeDeckId: deck.id };
}

export function addCard(
  library: Library,
  deckId: string,
  card: Omit<Card, "id"> & { id?: string },
): Library {
  return updateDeck(library, deckId, (deck) => ({
    ...deck,
    cards: [...deck.cards, { ...card, id: card.id ?? newId("card"), seconds: clampSeconds(card.seconds) }],
  }));
}

export function updateCard(library: Library, deckId: string, cardId: string, patch: Partial<Omit<Card, "id">>): Library {
  return updateDeck(library, deckId, (deck) => ({
    ...deck,
    cards: deck.cards.map((c) =>
      c.id === cardId ? { ...c, ...patch, seconds: clampSeconds(patch.seconds ?? c.seconds) } : c,
    ),
  }));
}

export function removeCard(library: Library, deckId: string, cardId: string): Library {
  return updateDeck(library, deckId, (deck) => ({ ...deck, cards: deck.cards.filter((c) => c.id !== cardId) }));
}

// Swap a card with its neighbour inside the same round.
export function moveCard(library: Library, deckId: string, cardId: string, direction: -1 | 1): Library {
  return updateDeck(library, deckId, (deck) => {
    const card = deck.cards.find((c) => c.id === cardId);
    if (!card) return deck;
    const sameRound = deck.cards.filter((c) => c.roundId === card.roundId);
    const neighbour = sameRound[sameRound.indexOf(card) + direction];
    if (!neighbour) return deck;
    const cards = [...deck.cards];
    const a = cards.indexOf(card);
    const b = cards.indexOf(neighbour);
    [cards[a], cards[b]] = [cards[b], cards[a]];
    return { ...deck, cards };
  });
}

export function addRound(library: Library, deckId: string, title: string): Library {
  return updateDeck(library, deckId, (deck) => ({
    ...deck,
    rounds: [...deck.rounds, { id: newId("round"), title: title.trim() || `Round ${deck.rounds.length + 1}` }],
  }));
}

export function moveRound(library: Library, deckId: string, roundId: string, direction: -1 | 1): Library {
  return updateDeck(library, deckId, (deck) => {
    const i = deck.rounds.findIndex((r) => r.id === roundId);
    const j = i + direction;
    if (i < 0 || j < 0 || j >= deck.rounds.length) return deck;
    const rounds = [...deck.rounds];
    [rounds[i], rounds[j]] = [rounds[j], rounds[i]];
    return { ...deck, rounds };
  });
}

export function clampSeconds(value: number): number {
  if (!Number.isFinite(value)) return 30;
  return Math.min(600, Math.max(5, Math.round(value)));
}

// The match: cards in round order, then card order inside each round.
export function playOrder(deck: Deck): Card[] {
  return deck.rounds.flatMap((round) => deck.cards.filter((c) => c.roundId === round.id));
}

export type RoundPacing = { roundId: string; title: string; cards: number; seconds: number; share: number };

export function pacing(deck: Deck): { total: number; rounds: RoundPacing[] } {
  const total = deck.cards.reduce((sum, c) => sum + c.seconds, 0);
  return {
    total,
    rounds: deck.rounds.map((round) => {
      const cards = deck.cards.filter((c) => c.roundId === round.id);
      const seconds = cards.reduce((sum, c) => sum + c.seconds, 0);
      return { roundId: round.id, title: round.title, cards: cards.length, seconds, share: total ? seconds / total : 0 };
    }),
  };
}

export function formatSeconds(seconds: number): string {
  const m = Math.floor(seconds / 60);
  const s = seconds % 60;
  return `${m}:${String(s).padStart(2, "0")}`;
}

import type { Library } from "./deck";
import { sampleLibrary } from "./sample-library";

export type LibraryStore = {
  load(): Library;
  save(library: Library): void;
  reset(): Library;
};

const KEY = "deck.library.v1";

function clone(library: Library): Library {
  return JSON.parse(JSON.stringify(library)) as Library;
}

function isLibrary(value: unknown): value is Library {
  const v = value as Library | null;
  return Boolean(v && Array.isArray(v.decks) && v.decks.length > 0 && typeof v.activeDeckId === "string");
}

// The only code that touches localStorage. Blocked or corrupt storage falls
// back to the sample library so the app still opens.
export function createLocalStore(storage: Storage | undefined = globalThis.localStorage): LibraryStore {
  return {
    load() {
      try {
        const raw = storage?.getItem(KEY);
        const parsed: unknown = raw ? JSON.parse(raw) : null;
        return isLibrary(parsed) ? parsed : clone(sampleLibrary);
      } catch {
        return clone(sampleLibrary);
      }
    },
    save(library) {
      try {
        storage?.setItem(KEY, JSON.stringify(library));
      } catch {
        // Storage is full or blocked. The session keeps working in memory.
      }
    },
    reset() {
      try {
        storage?.removeItem(KEY);
      } catch {
        // ignore
      }
      return clone(sampleLibrary);
    },
  };
}

export function createMemoryStore(initial: Library = sampleLibrary): LibraryStore {
  let current = clone(initial);
  return {
    load: () => clone(current),
    save: (library) => {
      current = clone(library);
    },
    reset: () => {
      current = clone(sampleLibrary);
      return clone(current);
    },
  };
}
