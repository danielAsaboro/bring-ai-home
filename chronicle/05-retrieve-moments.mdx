We will search the archive with a vague, half-remembered sentence and get back ranked memories. The model supplies vectors. The app ranks them, drops weak matches, and shows its scores.

People rarely remember the title of a memory. They remember a red blanket or a kite that would not fly. Retrieval should meet them there, and admit when nothing matches.

## Build and observe

### 1. Search with a vague sentence

Build the index first, then search:

```bash
npm run qvac:index-smoke
npm run qvac:retrieve-smoke
npm run qvac:retrieve-smoke -- "snow on the roof and the lights still on"
```

The default sentence never says "Gull Point" or "picnic". Check whether "Picnic at Gull Point" ranks first anyway. Read each `score`.

### 2. Try a sentence about nothing in the archive

```bash
npm run qvac:retrieve-smoke -- "my first day at a new job in an office"
```

Fewer results, or none, is the right answer. `minScore` is 0.3. The app decides this floor, not the model. Tune it on your own archive and write down why.

### 3. Catch a model mismatch

`retrieveMoments` throws when the query vector has a different size from the index. That happens when the index was built with another model. Rebuild the index; do not pad or trim vectors.

```typescript
import type { MemoryIndex } from "./memory-index";

export type RetrievedMoment = {
  memoryId: string;
  score: number;
};

export function cosineSimilarity(a: number[], b: number[]): number {
  if (a.length !== b.length || a.length === 0) {
    throw new Error("Vectors must have the same, non-zero length");
  }
  let dot = 0;
  let normA = 0;
  let normB = 0;
  for (let i = 0; i < a.length; i += 1) {
    dot += a[i] * b[i];
    normA += a[i] * a[i];
    normB += b[i] * b[i];
  }
  if (normA === 0 || normB === 0) return 0;
  return dot / (Math.sqrt(normA) * Math.sqrt(normB));
}

// The model only supplies vectors. The app ranks, filters, and decides.
export function retrieveMoments(
  index: MemoryIndex,
  queryVector: number[],
  options: { limit: number; minScore: number },
): RetrievedMoment[] {
  if (queryVector.length !== index.dimensions) {
    throw new Error(
      `Query has ${queryVector.length} dimensions; the index uses ${index.dimensions}`,
    );
  }
  return index.entries
    .map((entry) => ({
      memoryId: entry.memoryId,
      score: cosineSimilarity(entry.vector, queryVector),
    }))
    .filter((moment) => moment.score >= options.minScore)
    .sort((a, b) => b.score - a.score || a.memoryId.localeCompare(b.memoryId))
    .slice(0, options.limit);
}
```

import { describe, expect, it } from "vitest";

import type { MemoryIndex } from "./memory-index";
import { cosineSimilarity, retrieveMoments } from "./retrieve";

// Fixture index with hand-made vectors. Not model output.
const fixtureIndex: MemoryIndex = {
  model: "fixture",
  dimensions: 3,
  entries: [
    { memoryId: "m-beach-1998", text: "", vector: [1, 0, 0] },
    { memoryId: "m-train-2001", text: "", vector: [0, 1, 0] },
    { memoryId: "m-snow-2010", text: "", vector: [0.7, 0.7, 0] },
  ],
};

describe("retrieval", () => {
  it("scores identical directions as 1 and opposite as -1", () => {
    expect(cosineSimilarity([1, 2], [2, 4])).toBeCloseTo(1);
    expect(cosineSimilarity([1, 0], [-1, 0])).toBeCloseTo(-1);
  });

  it("returns the closest moments first and drops weak matches", () => {
    const moments = retrieveMoments(fixtureIndex, [0.9, 0.1, 0], {
      limit: 2,
      minScore: 0.3,
    });
    expect(moments.map((m) => m.memoryId)).toEqual(["m-beach-1998", "m-snow-2010"]);
  });

  it("returns nothing rather than a forced guess when nothing is close", () => {
    expect(
      retrieveMoments(fixtureIndex, [0, 0, 1], { limit: 3, minScore: 0.3 }),
    ).toEqual([]);
  });

  it("rejects a query from a different embedding model", () => {
    expect(() =>
      retrieveMoments(fixtureIndex, [1, 0], { limit: 3, minScore: 0 }),
    ).toThrow("Query has 2 dimensions; the index uses 3");
  });
});

<Accordion title="qvac-service/retrieve-smoke.mjs">

```javascript
import { readFile, writeFile } from "node:fs/promises";
import path from "node:path";
import { fileURLToPath } from "node:url";

const appDirectory = fileURLToPath(new URL("../", import.meta.url));
const qvacDirectory = path.join(appDirectory, ".qvac");
const cacheDirectory = path.join(qvacDirectory, "models");
const configPath = path.join(qvacDirectory, "config.json");
const indexPath = path.join(qvacDirectory, "archive-index.json");
const recollection =
  process.argv.slice(2).join(" ") ||
  "that time on the sand with the red blanket, when the kite would not go up";

let modelId;
let sdk;
try {
  const { retrieveMoments } = await import("../src/features/chronicle/retrieve.ts");
  const { sampleArchive } = await import("../src/features/chronicle/archive.ts");
  const index = JSON.parse(await readFile(indexPath, "utf8"));

  await writeFile(
    configPath,
    `${JSON.stringify({ cacheDirectory }, null, 2)}\n`,
    "utf8",
  );
  process.env.QVAC_CONFIG_PATH = configPath;

  sdk = await import("@qvac/sdk");
  modelId = await sdk.loadModel({
    modelSrc: sdk.GTE_LARGE_FP16,
    modelType: "embeddings",
  });
  const { embedding } = await sdk.embed({ modelId, text: recollection });
  const moments = retrieveMoments(index, embedding, { limit: 3, minScore: 0.3 });
  process.stdout.write(
    `${JSON.stringify(
      {
        recollection,
        model: index.model,
        moments: moments.map((moment) => ({
          ...moment,
          title: sampleArchive.find((m) => m.id === moment.memoryId)?.title,
        })),
      },
      null,
      2,
    )}\n`,
  );
} catch (error) {
  const message = error instanceof Error ? error.message : String(error);
  process.stderr.write(
    `QVAC retrieve smoke failed: ${message}\nRun npm run qvac:index-smoke first to build ${indexPath}.\n`,
  );
  process.exitCode = 1;
} finally {
  if (sdk && modelId) {
    await sdk.unloadModel({ modelId, clearStorage: false }).catch(() => undefined);
  }
  if (sdk) await sdk.close().catch(() => undefined);
}
```
