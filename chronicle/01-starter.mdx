We will run the Chronicle starter, look at a small fictional family archive, and record a clean baseline. Every later chapter starts from this commit.

Chronicle is a private family archive shaped like a flip magazine. The starter has no AI in it. That is on purpose. We add local AI one step at a time, and the app must keep working without it.

**Source checkpoint:** `c723afb` · **Starting checkpoint:** `c082ba9`

## What you change

This chapter adds a fictional sample archive and lists it on the home page.

| File | Responsibility |
| --- | --- |
| `src/features/chronicle/archive.ts` | Six fictional memories and a date sort |
| `src/app/page.tsx` | Render the archive as an ordered list |
| `public/test-files/chronicle/*.png` | Three fictional drawn photos used in later chapters |

Every name, place, and photo is invented. Keep real family media out of the repository.

## Build and observe

### 1. Get the code

```bash
git clone https://github.com/danielAsaboro/bring-ai-home
cd bring-ai-home
git checkout c723afb
node --version
npm ci
npm run dev
```

Each lesson checkpoint holds the app at the repository root. The finished app is the tip of branch `course/chronicle-qvac`.

Use Node 22.22.2 or newer. Open `http://localhost:3000`.

### 2. Read the archive

You should see six memories, oldest first. "First tomatoes" (1995) is at the top. "School band concert" (2013) is at the bottom.

Open `src/features/chronicle/archive.ts`. Each memory has a title, a date, people, and a caption. A person wrote each of these. Later chapters may propose new text, but they never overwrite these fields.

### 3. Look at the sample photos

Open the three PNG files in `public/test-files/chronicle`. They are simple drawings: a beach picnic, a birthday cake, and a snowy house. They are fictional test media. We use them because they are safe to share and easy to judge by eye.

### 4. Write down the rule for this course

> QVAC may propose descriptions, transcripts, and matches. Only a person may turn a proposal into archive content.

We will test this rule in every chapter.

<Accordion title="src/app/page.tsx">

```tsx
import { memoriesByDate, sampleArchive } from "@/features/chronicle/archive";

export default function Home() {
  return (
    <main>
      <h1>Chronicle</h1>
      <ol aria-label="Archive">
        {memoriesByDate(sampleArchive).map((memory) => (
          <li key={memory.id}>
            <h2>{memory.title}</h2>
            <p>
              <time dateTime={memory.date}>{memory.date}</time> ·{" "}
              {memory.people.join(", ")}
            </p>
            <p>{memory.caption}</p>
          </li>
        ))}
      </ol>
    </main>
  );
}
```
