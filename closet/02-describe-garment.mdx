## Build and observe

### Before you start on Linux

Two install problems show up on Linux. Apply each fix only if it applies to you.

- If the QVAC worker reports `Cannot find module 'b4a'`, check that `b4a` is in `package.json`. This checkpoint already adds it.
- If `ls -l node_modules/bare-runtime-linux-x64/bin/bare` shows no `x`, run `chmod +x node_modules/bare-runtime-linux-x64/bin/bare`.

### 1. Install the pinned runtime

```bash
npm ci
```

The lockfile pins `@qvac/sdk` 0.22.0. Do not run a floating `npm install @qvac/sdk`.

### 2. Why `b4a` is a direct dependency

QVAC runs inference in a separate worker on the Bare runtime. When that worker cannot start, the SDK only reports an RPC timeout. Running the worker directly shows the real cause: a nested package imports `b4a` without declaring it. Adding `b4a` as a direct dependency fixes the install boundary. No QVAC code changes.

### 3. Prepare configuration before importing QVAC

Open `describe-garment-smoke.mjs`. It creates `.qvac/models`, writes `.qvac/config.json`, and sets `QVAC_CONFIG_PATH`. Only then does it `await import("@qvac/sdk")`. The SDK reads its config when it starts, so the order matters.

### 4. Read the model lifecycle

`loadModel` loads `SMOLVLM2_500M_MULTIMODAL_Q8_0` with its projection model `MMPROJ_SMOLVLM2_500M_MULTIMODAL_Q8_0`. The projection model is what lets the language model read an image. `completion` takes one user message with `attachments: [{ path }]` and streams tokens. The `finally` block unloads the model and closes the SDK even after an error.

### 5. Run it twice

```bash
npm run qvac:describe-smoke
npm run qvac:describe-smoke public/garments/striped-breton.png
```

The first run downloads model files into `.qvac/models`. Later runs reuse them. Read `kind`, `sourceDigest`, `description`, and `loadMs`. Compare the description with the drawing. A 500M model can miss the stripes or call a blazer a shirt. That is why it only proposes.

### 6. If the download stalls

QVAC fetches models from its own registry, not from npm. On a network that blocks that registry the log stops at the download step and the cache files stay empty. That is a network failure; rerun on a machine with normal internet. Do not change code to fix it.

We built this course in a container that blocks the registry, so this chapter's receipt is the focused test below, not a live description. Run the smoke command yourself to see real output.

```javascript
import { createHash } from "node:crypto";
import { mkdir, readFile, writeFile } from "node:fs/promises";
import path from "node:path";
import { fileURLToPath } from "node:url";

const { resolveLocalQvacPaths, buildGarmentDescription, VISION_MODEL, DESCRIBE_GARMENT_PROMPT } =
  await import("./local-config.ts");

const appDirectory = fileURLToPath(new URL("../", import.meta.url));
const sourcePath = path.resolve(
  process.argv[2] ?? path.join(appDirectory, "public/garments/yellow-raincoat.png"),
);
const { cacheDirectory, configPath } = resolveLocalQvacPaths(appDirectory);

let sdk;
let modelId;
try {
  const sourceBytes = await readFile(sourcePath);
  const sourceDigest = createHash("sha256").update(sourceBytes).digest("hex");

  // The SDK reads its config at import time, so write it first.
  await mkdir(cacheDirectory, { recursive: true });
  await writeFile(configPath, `${JSON.stringify({ cacheDirectory }, null, 2)}\n`, "utf8");
  process.env.QVAC_CONFIG_PATH = configPath;

  sdk = await import("@qvac/sdk");
  const startedAt = Date.now();
  modelId = await sdk.loadModel({
    modelSrc: sdk.SMOLVLM2_500M_MULTIMODAL_Q8_0,
    modelConfig: { ctx_size: 1024, projectionModelSrc: sdk.MMPROJ_SMOLVLM2_500M_MULTIMODAL_Q8_0 },
    onProgress: (p) => process.stderr.write(`Downloading ${p.percentage.toFixed(0)}%\n`),
  });
  const loadMs = Date.now() - startedAt;
  const run = sdk.completion({
    modelId,
    history: [{ role: "user", content: DESCRIBE_GARMENT_PROMPT, attachments: [{ path: sourcePath }] }],
    stream: true,
  });
  let rawText = "";
  for await (const token of run.tokenStream) rawText += token;
  const result = buildGarmentDescription({
    sourceName: path.basename(sourcePath),
    sourceDigest,
    model: VISION_MODEL,
    rawText,
    stats: await run.stats,
  });
  process.stdout.write(`${JSON.stringify({ ...result, loadMs }, null, 2)}\n`);
} catch (error) {
  process.stderr.write(
    `QVAC describe smoke failed: ${error instanceof Error ? error.message : String(error)}\n` +
      `The first successful run downloads model files into ${cacheDirectory}; later runs reuse that cache.\n`,
  );
  process.exitCode = 1;
} finally {
  if (sdk && modelId) await sdk.unloadModel({ modelId, clearStorage: false }).catch(() => undefined);
  if (sdk) await sdk.close().catch(() => undefined);
}
```

<Accordion title="qvac-service/local-config.ts">

```typescript
import path from "node:path";

export function resolveLocalQvacPaths(appDirectory: string) {
  const qvacDirectory = path.join(appDirectory, ".qvac");
  return {
    qvacDirectory,
    cacheDirectory: path.join(qvacDirectory, "models"),
    configPath: path.join(qvacDirectory, "config.json"),
  };
}

export const VISION_MODEL = "SMOLVLM2_500M_MULTIMODAL_Q8_0";

export const DESCRIBE_GARMENT_PROMPT =
  "Describe this garment in one plain sentence: what kind of clothing it is, its main colour, and any visible pattern. Mention only what is visible.";

export type GarmentDescription<TStats> = {
  kind: "proposed-description";
  sourceName: string;
  sourceDigest: string;
  model: string;
  description: string;
  stats: TStats | null;
};

// A model description is a proposal. It never edits a garment by itself.
export function buildGarmentDescription<TStats>(input: {
  sourceName: string;
  sourceDigest: string;
  model: string;
  rawText: string;
  stats: TStats | undefined;
}): GarmentDescription<TStats> {
  const description = input.rawText.replace(/\s+/g, " ").trim();
  if (description.length === 0) {
    throw new Error("The model returned an empty description");
  }
  return {
    kind: "proposed-description",
    sourceName: input.sourceName,
    sourceDigest: input.sourceDigest,
    model: input.model,
    description,
    stats: input.stats ?? null,
  };
}
```

```typescript
import path from "node:path";
import { describe, expect, it } from "vitest";

import { buildGarmentDescription, resolveLocalQvacPaths } from "./local-config";

describe("local QVAC paths", () => {
  it("keeps the model cache inside the app's ignored .qvac folder", () => {
    const paths = resolveLocalQvacPaths("/work/closet");
    expect(paths.cacheDirectory).toBe(path.join("/work/closet", ".qvac", "models"));
    expect(paths.configPath).toBe(path.join("/work/closet", ".qvac", "config.json"));
  });
});

describe("garment description", () => {
  // Fixture text written by hand for this test. It is not model output.
  const fixtureText = "  A yellow raincoat\n with a front seam.  ";

  it("labels the text as a proposal and normalises whitespace", () => {
    const result = buildGarmentDescription({
      sourceName: "yellow-raincoat.png",
      sourceDigest: "abc",
      model: "SMOLVLM2_500M_MULTIMODAL_Q8_0",
      rawText: fixtureText,
      stats: undefined,
    });
    expect(result.kind).toBe("proposed-description");
    expect(result.description).toBe("A yellow raincoat with a front seam.");
    expect(result.stats).toBeNull();
  });

  it("rejects an empty description instead of inventing one", () => {
    expect(() =>
      buildGarmentDescription({ sourceName: "x.png", sourceDigest: "abc", model: "m", rawText: "  ", stats: undefined }),
    ).toThrow("empty description");
  });
});
```
