We will run the Ledger starter, look at what it does today, and pin the fictional receipt the whole course reads. Nothing in this chapter uses AI.

The starter is the foundation of an owned account book. It is small on purpose. We add local AI to it one chapter at a time and keep every check green.

**Source checkpoint:** `d5d540a` · **Starting checkpoint:** `47e8cea` (untouched starter, first commit on `course/ledger-qvac`)

## What changes

- Add `public/test-files/ledger/receipt-corner-cafe.png`, a fictional receipt.
- Add a test that pins the receipt's SHA-256 digest.
- Add a short README note about the test file.

No application code changes. This is the baseline.

## Build and observe

### 1. Get the starter and start it

```bash
git clone https://github.com/danielAsaboro/bring-ai-home
cd bring-ai-home
git checkout d5d540a
node --version
npm ci
npm run dev
```

Open `http://localhost:3000`. You should see the **Ledger** heading. That is the whole interface for now.

### 2. Look at the test receipt

Open `public/test-files/ledger/receipt-corner-cafe.png`. It is a made-up café receipt. It names no real business and no real card.

Read it as a person would. Three lines, a subtotal of **9.75**, tax of **0.78**, and a printed total of **10.53**. Remember those numbers. Later chapters check them in code.

### 3. Know the rule before adding AI

We will hold one rule for the whole course:

> QVAC may read receipts and propose drafts. Only a person may turn a draft into a ledger entry. Totals and balances are always calculated by deterministic code, never by a model.

### 4. Run the baseline checks

```bash
npm run lint
npm run typecheck
npm test
```

Run each command on its own and check that it exits cleanly.

<Accordion title="src/fixtures/test-files.test.ts">

```typescript
import { createHash } from "node:crypto";
import { readFileSync } from "node:fs";
import path from "node:path";
import { describe, expect, it } from "vitest";

const receiptPath = path.join(
  process.cwd(),
  "public/test-files/ledger/receipt-corner-cafe.png",
);

describe("course test files", () => {
  it("keeps the fictional receipt byte-for-byte stable", () => {
    const bytes = readFileSync(receiptPath);
    const digest = createHash("sha256").update(bytes).digest("hex");

    expect(digest).toBe(
      "8bc01b420180f7256015037199e78e0f4a6ffe158304caa169b76bae2b2f06cd",
    );
  });
});
```
