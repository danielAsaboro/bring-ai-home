# Bring AI Home brand kit

Free to use when you write about, link to, or build on Bring AI Home.
Download everything at once: https://bringaihome.xyz/brand/bring-ai-home-brand.zip

## The mark

A house that is also a chat bubble.
Three red thinking dots sit inside, and a red arrow drops out through the floor: the AI thinks at home and hands the answer to you, on your own device.

## Files

| File | Use it for |
| --- | --- |
| `svg/logo-light.svg`, `png/logo-light-2000.png` | Full logo on light backgrounds |
| `svg/logo-dark.svg`, `png/logo-dark-2000.png` | Full logo on dark backgrounds |
| `svg/mark-light.svg`, `svg/mark-dark.svg` | The icon alone |
| `svg/mark-mono-black.svg`, `svg/mark-mono-white.svg` | One-colour print and watermarks |
| `svg/app-icon-*.svg`, `png/app-icon-*-1024.png` | Avatars and app icons: dark, red, charcoal, light, red-dark, mono |
| `svg/favicon.svg`, `png/favicon-*.png` | Browser tabs and touch icons |
| `brand-sheet.png` | The original brand sheet |

## Colours

| Name | Hex | Role |
| --- | --- | --- |
| Signal Red | `#FC412C` | Dots, arrow, and the word "AI" only |
| Ink | `#0A0A0A` | Outline and wordmark on light backgrounds |
| Warm White | `#FAF7F2` | Outline and wordmark on dark backgrounds |
| Paper | `#F7F4ED` | Light background |
| Night | `#141413` | Dark background and dark app icon |
| Charcoal | `#1D1D1C` | Charcoal app icon |

## Please

- Leave clear space around the logo of at least the arrowhead's width.
- Don't go below 24px tall for the full logo or 20px for the icon; use the favicon below that.
- Don't recolour, stretch, outline, or add effects. Use the files as they are.
