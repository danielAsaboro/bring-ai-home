We will add the QVAC SDK and turn a recorded voice recap into text with a local Whisper model. The result is a proposed recap, never a saved timeline entry.

After a call, it is easier to talk for twenty seconds than to type. A transcript keeps that context on your own computer. The recap also describes someone else's life, which is why it should not leave the machine.

Whisper can mishear names. So the transcript is a proposal. Nothing is written to a person's card in this chapter.

## Build and observe

### 1. Install the pinned SDK

```bash
npm install --save-exact @qvac/sdk@0.22.0 b4a@1.9.0
```

On Linux, if the native runtime will not start, make it executable. This is a local fix and is not committed:

```bash
chmod +x node_modules/bare-runtime-linux-x64/bin/bare
```

### 2. Record your own recap

We do not ship a voice recording. Record about fifteen seconds and save it as WAV. Read this fictional line:

> Coffee with Dev today. He is nervous about the meetup on the twenty-eighth. I said I would send him my slide template by Friday.

Keep the file outside the repository. A voice is personal data, and `.gitignore` now ignores `*.wav`.

### 3. Run the transcription

```bash
npm run qvac:transcribe-smoke -- ~/Downloads/dev-recap.wav
```

The first run downloads the Whisper model into `.qvac/models`. Later runs reuse that cache. Compare `transcript` with what you said, especially the names.

### 4. Read the lifecycle

The script writes the config, then imports the SDK, then calls `loadModel`, `transcribe`, `unloadModel`, and `close`, in that order. `metadata: true` returns segments with `startMs` and `endMs`. `buildRecapDraft` throws `No speech was recognised in this recap` when every segment is empty. It never invents text.

import { describe, expect, it } from "vitest";

import { buildRecapDraft } from "./recap";

// FIXTURE: hand-written segments shaped like `transcribe({ metadata: true })`.
// They are not model output and prove nothing about live inference.
const fixtureSegments = [
  { text: " Just got off the phone with Dev.", startMs: 0, endMs: 2100 },
  { text: "   ", startMs: 2100, endMs: 2600 },
  { text: "I promised to send him the slide template by Friday.", startMs: 2600, endMs: 5900 },
];

describe("buildRecapDraft", () => {
  it("joins spoken segments into a proposed recap", () => {
    const draft = buildRecapDraft(fixtureSegments, "WHISPER_TINY");
    expect(draft.status).toBe("proposed");
    expect(draft.transcript).toBe(
      "Just got off the phone with Dev. I promised to send him the slide template by Friday.",
    );
    expect(draft.segments).toHaveLength(2);
    expect(draft.durationMs).toBe(5900);
  });

  it("refuses to invent text for silence", () => {
    expect(() =>
      buildRecapDraft([{ text: " ", startMs: 0, endMs: 900 }], "WHISPER_TINY"),
    ).toThrow("No speech");
  });
});

<Accordion title="qvac-service/recap.ts">

```typescript
export type RecapSegment = {
  text: string;
  startMs: number;
  endMs: number;
};

// A transcript is a proposal. Nothing here writes to a person's timeline.
export type RecapDraft = {
  status: "proposed";
  source: "local-transcription";
  model: string;
  transcript: string;
  durationMs: number;
  segments: RecapSegment[];
};

export function buildRecapDraft(
  segments: RecapSegment[],
  model: string,
): RecapDraft {
  const kept = segments
    .map((s) => ({ ...s, text: s.text.replace(/\s+/g, " ").trim() }))
    .filter((s) => s.text.length > 0);
  if (kept.length === 0) {
    throw new Error("No speech was recognised in this recap");
  }
  return {
    status: "proposed",
    source: "local-transcription",
    model,
    transcript: kept.map((s) => s.text).join(" "),
    durationMs: Math.max(...kept.map((s) => s.endMs)),
    segments: kept,
  };
}
```

<Accordion title="qvac-service/transcribe-recap-smoke.mjs">

```javascript
import { createHash } from "node:crypto";
import { access, mkdir, readFile, writeFile } from "node:fs/promises";
import path from "node:path";
import { fileURLToPath } from "node:url";

const appDirectory = fileURLToPath(new URL("../", import.meta.url));
if (!process.argv[2]) {
  process.stderr.write(
    "Usage: npm run qvac:transcribe-smoke -- <path-to-your-recap.wav>\n",
  );
  process.exit(1);
}
const sourcePath = path.resolve(process.argv[2]);
const qvacDirectory = path.join(appDirectory, ".qvac");
const cacheDirectory = path.join(qvacDirectory, "models");
const configPath = path.join(qvacDirectory, "config.json");

let modelId;
let sdk;
try {
  const { buildRecapDraft } = await import("./recap.ts");
  await access(sourcePath);
  const sourceDigest = createHash("sha256")
    .update(await readFile(sourcePath))
    .digest("hex");
  await mkdir(cacheDirectory, { recursive: true });
  await writeFile(configPath, `${JSON.stringify({ cacheDirectory }, null, 2)}\n`, "utf8");
  process.env.QVAC_CONFIG_PATH = configPath;

  sdk = await import("@qvac/sdk");
  modelId = await sdk.loadModel({
    modelSrc: sdk.WHISPER_TINY,
    modelConfig: { language: "en", translate: false, temperature: 0.0 },
    onProgress: (p) => process.stderr.write(`Downloading ${p.percentage.toFixed(0)}%\n`),
  });
  const segments = await sdk.transcribe({ modelId, audioChunk: sourcePath, metadata: true });
  const draft = buildRecapDraft(segments, "WHISPER_TINY");
  process.stdout.write(
    `${JSON.stringify({ sourceName: path.basename(sourcePath), sourceDigest, ...draft }, null, 2)}\n`,
  );
} catch (error) {
  const message = error instanceof Error ? error.message : String(error);
  process.stderr.write(`QVAC transcribe smoke failed: ${message}\n`);
  process.exitCode = 1;
} finally {
  if (sdk && modelId) {
    await sdk.unloadModel({ modelId, clearStorage: false }).catch(() => undefined);
  }
  if (sdk) await sdk.close().catch(() => undefined);
}
```
