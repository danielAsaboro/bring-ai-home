## Build and observe

### 1. Work out the known box by hand

The controlled page is 1200 pixels wide and 1600 pixels high. One historical OCR box was `[211, 114, 397, 158]`.

```text
x      = 211 / 1200 × 100        = 17.583333
 y     = 114 / 1600 × 100        = 7.125
width  = (397 - 211) / 1200 × 100 = 15.5
height = (158 - 114) / 1600 × 100 = 2.75
```

The raw tuple contains edges. The editor object contains origin plus size. Dividing all four raw numbers by image size without subtracting edges would produce the wrong dimensions.

### 2. Implement the conversion boundary

Read the complete `ocr-geometry.ts` below. The order is finite dimensions, finite edges, sorting, clipping, rejecting empty geometry, then percentage conversion. Six-decimal rounding stabilizes stored values without pretending that pixels have infinite precision.

### 3. Exercise hostile inputs

Read `ocr-geometry.test.ts`. Trace a reversed box, a partially clipped box, a fully clipped box, NaN, and a zero-area region through the function. Invalid source dimensions throw; unusable individual blocks return `null`.

Write down why these two cases differ: we can omit one bad evidence region, but cannot honestly interpret any region on a page with invalid dimensions.

### 4. Connect the result to the existing surface

Inspect the patch changes in `RedactApp.tsx`, `workflow-domain.ts`, and `DocumentSurface.tsx`. Preserve the raw tuple for the receipt and add normalized geometry for display. Filter by page identity.

The surface must display `page.pngBytes`, use the same aspect ratio, and position evidence inside that image's container. A thumbnail or differently cropped image is not an interchangeable geometry reference.

### 5. Observe the separation

Run the app and service, then analyze the chat page. Evidence outlines should align with the text on Original. Safe-share preview should remain uncovered until you draw a manual mark. Detected text is not an approved redaction.

```typescript
import type { BoundingBox } from "./workflow-domain";

function clamp(value: number, maximum: number) {
  return Math.max(0, Math.min(maximum, value));
}

function percentage(value: number, maximum: number) {
  return Math.round((value / maximum) * 100 * 1_000_000) / 1_000_000;
}

export function normalizeOcrBbox(
  raw: readonly [number, number, number, number],
  sourceWidth: number,
  sourceHeight: number,
): BoundingBox | null {
  if (!Number.isFinite(sourceWidth) || !Number.isFinite(sourceHeight) || sourceWidth <= 0 || sourceHeight <= 0) {
    throw new Error("Source dimensions must be positive");
  }
  if (!raw.every(Number.isFinite)) return null;

  const x1 = clamp(Math.min(raw[0], raw[2]), sourceWidth);
  const y1 = clamp(Math.min(raw[1], raw[3]), sourceHeight);
  const x2 = clamp(Math.max(raw[0], raw[2]), sourceWidth);
  const y2 = clamp(Math.max(raw[1], raw[3]), sourceHeight);
  if (x2 <= x1 || y2 <= y1) return null;

  return {
    x: percentage(x1, sourceWidth),
    y: percentage(y1, sourceHeight),
    width: percentage(x2 - x1, sourceWidth),
    height: percentage(y2 - y1, sourceHeight),
  };
}
```

```typescript
import { describe, expect, it } from "vitest";

import { normalizeOcrBbox } from "./ocr-geometry";

describe("OCR geometry normalization", () => {
  it("converts pixel edges to the editor percentage system", () => {
    expect(normalizeOcrBbox([211, 114, 397, 158], 1200, 1600)).toEqual({
      x: 17.583333,
      y: 7.125,
      width: 15.5,
      height: 2.75,
    });
  });

  it("sorts reversed edges and clips them to the decoded raster", () => {
    expect(normalizeOcrBbox([1300, 1700, -100, -200], 1200, 1600)).toEqual({
      x: 0,
      y: 0,
      width: 100,
      height: 100,
    });
  });

  it("rejects non-finite, zero-area, fully clipped, and invalid-source geometry", () => {
    expect(normalizeOcrBbox([0, 0, Number.NaN, 10], 1200, 1600)).toBeNull();
    expect(normalizeOcrBbox([10, 10, 10, 40], 1200, 1600)).toBeNull();
    expect(normalizeOcrBbox([-20, -20, -10, -10], 1200, 1600)).toBeNull();
    expect(() => normalizeOcrBbox([0, 0, 10, 10], 0, 1600)).toThrow(
      "Source dimensions must be positive",
    );
  });
});
```
