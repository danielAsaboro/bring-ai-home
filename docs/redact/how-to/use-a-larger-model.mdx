---
title: "How to use a larger reasoning model"
description: "Swap Qwen3 0.6B for a bigger QVAC catalog model and check suggestion quality afterwards."
---

This guide replaces the model that classifies sensitive fields. OCR is unchanged. A larger model can improve suggestions, at the cost of download size, memory and time per page.

## Pick a model

Catalog constants in `@qvac/sdk` 0.22.0 that fit this role include:

| Constant | Notes |
|---|---|
| `QWEN3_600M_INST_Q4` | Default. About 382 MB. |
| `QWEN3_1_7B_INST_Q4` | Next size up. |
| `QWEN3_4B_INST_Q4_K_M` | |
| `QWEN3_8B_INST_Q4_K_M` | |

Check that your machine can hold it before downloading. See [Assess model fit](https://docs.qvac.tether.io/sdk/models/assess-model-fit/) and [About choosing a model size](/docs/redact/concepts/model-size).

## Change the model

The model is chosen in three entry points. Change all three so the service, the evaluation and the offline proof run the same model:

| File | Change |
|---|---|
| `qvac-service/index.ts` | `modelSource: qvac.QWEN3_600M_INST_Q4` |
| `qvac-service/evaluation-cli.ts` | `modelSource: qvac.QWEN3_600M_INST_Q4` |
| `qvac-service/offline-cli.ts` | `modelSource: qvac.QWEN3_600M_INST_Q4` |

Replace `QWEN3_600M_INST_Q4` with your constant in each.

Then update the labels that name the model, so receipts don't lie:

- `qvac-service/reasoning.ts`: the `id: "qwen3-600m-instruct-q4"` returned by `getState()`. The app shows this id in each analysis receipt.
- `qvac-service/evaluation.ts`: `reasoning: "QWEN3_600M_INST_Q4/qwen3-600m-instruct-q4"` in `EVALUATION_IDENTIFIERS`.

Keep `ctx_size: 4096` in `reasoning.ts` unless a page has more OCR text than fits.

## Check it

```bash
npm run typecheck
npm test
npm run qvac:evaluate
```

`qvac:evaluate` downloads the new model on first run. Compare precision, recall and F1 per case with the previous model; see [evaluation reference](/docs/redact/reference/evaluation). If `"passed": false`, keep the old model or adjust the prompt before shipping.

`offline-proof.ts` checks the cache for a file name containing `qwen`. If you switch to a non-Qwen model, update `assertWarmedCache` too.
