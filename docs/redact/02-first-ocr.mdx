## Build and observe

### 1. Add the pinned runtime and smoke command

The chapter patch adds `@qvac/sdk` at **0.17.1**, records the Node floor, updates the lockfile, adds `qvac:ocr-smoke`, and creates the local configuration files and tests. Read the patch's package changes before applying it. Use its lockfile with `npm ci`; do not combine this chapter with a floating SDK install.

### 2. Prepare configuration before importing QVAC

Open `qvac-service/ocr-smoke.mjs`. It resolves the source and project directory, creates `.qvac/models`, writes `.qvac/config.json`, and sets `QVAC_CONFIG_PATH`. Only then does it dynamically import the SDK.

The order is intentional: the SDK must see the app-owned configuration when it initializes. The model cache is ignored local runtime data, not course source.

### 3. Read the model lifecycle

Find `loadModel`, `ocr`, `unloadModel`, and `close` in the complete implementation below. `loadModel` returns an instance identifier used by `ocr`. The smoke command awaits blocks and statistics together. The `finally` block unloads active memory while retaining disk assets and closes the SDK even after an error.

`paragraph: false` preserves individual regions. This makes the evidence and its location inspectable before any application policy is applied.

### 4. Run the image twice

```bash
npm run qvac:ocr-smoke
npm run qvac:ocr-smoke
```

The first successful run can download model assets. The second should reuse the cache. Read `sourceName`, `sourceDigest`, `cacheDirectory`, `blocks`, and `stats` in the JSON output. Compare a few returned strings to the source image.

The script's historical image produced 12 blocks and imperfect email punctuation. Your count and timings may differ; successful live inference and a matching source digest are the required observations, not a forced reproduction of those numbers.

### 5. Diagnose before changing code

If the worker reports a missing native plugin, complete `npm ci` before editing the OCR configuration. If a model download fails, resolve acquisition first. If npm reports a cache permission error, use a writable scoped cache, for example `npm ci --cache /private/tmp/redact-course-npm-cache`.

OCR recognition confidence answers how clearly text was read. It does not answer whether that text should be hidden.

<Accordion title="qvac-service/ocr-smoke.mjs">

```javascript
import { createHash } from "node:crypto";
import { access, mkdir, readFile, writeFile } from "node:fs/promises";
import path from "node:path";
import { fileURLToPath } from "node:url";

const appDirectory = fileURLToPath(new URL("../", import.meta.url));
const defaultSource = fileURLToPath(
  new URL("../public/test-files/redact/chat-private.png", import.meta.url),
);
const sourcePath = path.resolve(process.argv[2] ?? defaultSource);
const sourceName = path.basename(sourcePath);
const qvacDirectory = path.join(appDirectory, ".qvac");
const cacheDirectory = path.join(qvacDirectory, "models");
const configPath = path.join(qvacDirectory, "config.json");

let modelId;
let sdk;
try {
  await access(sourcePath);
  const sourceBytes = await readFile(sourcePath);
  const sourceDigest = createHash("sha256").update(sourceBytes).digest("hex");
  await mkdir(cacheDirectory, { recursive: true });
  await writeFile(
    configPath,
    `${JSON.stringify({ cacheDirectory }, null, 2)}\n`,
    "utf8",
  );
  process.env.QVAC_CONFIG_PATH = configPath;

  sdk = await import("@qvac/sdk");
  modelId = await sdk.loadModel({
    modelSrc: sdk.OCR_LATIN,
    modelConfig: {
      langList: ["en"],
      magRatio: 1.5,
      defaultRotationAngles: [90, 180, 270],
      contrastRetry: false,
      lowConfidenceThreshold: 0.5,
      recognizerBatchSize: 1,
    },
  });
  const run = sdk.ocr({
    modelId,
    image: sourcePath,
    options: { paragraph: false },
  });
  const [blocks, stats] = await Promise.all([run.blocks, run.stats]);
  process.stdout.write(
    `${JSON.stringify(
      {
        sourceName,
        sourceDigest,
        cacheDirectory,
        blocks,
        stats: stats ?? null,
      },
      null,
      2,
    )}\n`,
  );
} catch (error) {
  const message = error instanceof Error ? error.message : String(error);
  process.stderr.write(
    `QVAC OCR smoke failed: ${message}\nThe first successful run downloads OCR assets into ${qvacDirectory}; warmed runs reuse that local cache.\n`,
  );
  process.exitCode = 1;
} finally {
  if (sdk && modelId) {
    await sdk.unloadModel({ modelId, clearStorage: false }).catch(() => undefined);
  }
  if (sdk) await sdk.close().catch(() => undefined);
}
```

```typescript
import path from "node:path";

export function resolveLocalQvacPaths(appDirectory: string) {
  const qvacDirectory = path.join(appDirectory, ".qvac");
  return {
    qvacDirectory,
    cacheDirectory: path.join(qvacDirectory, "models"),
    configPath: path.join(qvacDirectory, "config.json"),
  };
}

export function buildOcrReceipt<TBlock, TStats>(input: {
  sourceName: string;
  sourceDigest: string;
  cacheDirectory: string;
  blocks: TBlock[];
  stats: TStats;
}) {
  return {
    sourceName: input.sourceName,
    sourceDigest: input.sourceDigest,
    cacheDirectory: input.cacheDirectory,
    blocks: input.blocks,
    stats: input.stats,
  };
}
```
