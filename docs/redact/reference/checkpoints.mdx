## Getting a checkpoint

Clone once, then start a branch of your own at any tag:

```bash
git clone https://github.com/danielAsaboro/bring-ai-home
cd bring-ai-home
git switch -c my-redact redact-01-starter
```

The app is in the `redact/` folder of every checkpoint.

## Stepping to the next lesson

From your branch at the previous lesson, bring in the next lesson's commit:

```bash
git cherry-pick redact-02-first-ocr
```

The **compare** link in the table shows exactly what that commit changes.
Run `npm ci` in `redact/` after a lesson that changes `package-lock.json` (lessons 02 and 03).
