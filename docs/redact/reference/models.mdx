Models download on first use into `redact/.qvac/models/` and load from there afterwards.

## OCR: `OCR_LATIN`

| Item | Value |
|---|---|
| SDK constant | `OCR_LATIN` |
| Health ID | `qvac-ocr-latin` |
| Files | `craft_mlt_25k.gguf` (detector, 83 MB), `latin_g2.gguf` (recognizer, 15 MB) |
| Loaded in | `qvac-service/qvac-analyzer.ts` |
| `langList` | `["en"]` |
| `magRatio` | `1.5` |
| `defaultRotationAngles` | `[90, 180, 270]` |
| `contrastRetry` | `false` |
| `lowConfidenceThreshold` | `0.5` |
| `recognizerBatchSize` | `1` |
| `ocr()` options | `{ paragraph: false }` |

Official page: [OCR](https://docs.qvac.tether.io/sdk/ai-capabilities/ocr/).

## Measured times

Apple Silicon Mac, 36 GB RAM, macOS 27, `@qvac/sdk` 0.22.0, the 1600 × 1200 test chat image.

| Step | Time |
|---|---|
| OCR, one page, model warm | 18–30 s |
| OCR, rotated page (two OCR passes) | about 35 s |
| Laya decisions, one page | 0.8–1 s |
| Qwen suggestions, one page | 2–9 s |
| Copy check after **Done**, one page | about 25 s |
| First browser analysis, models downloading | about 3 min (one measurement) |
| Labelled evaluation, four images | about 2 min |

Pages are analysed one after another.
