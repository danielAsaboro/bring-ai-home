## Questions

Every question is `type: "noul"`: the answer is the probability that the statement holds.

| Question ID | Statement | Asked at |
|---|---|---|
| `name` | This text contains a person's name. | Private, Confidential |
| `email` | This text contains an email address. | Private, Confidential |
| `phone` | This text contains a telephone number. | Private, Confidential |
| `address` | This text contains a street address. | Private, Confidential |
| `account` | This text contains a bank, card or account number. | Private, Confidential |
| `identity` | This text contains a passport, national ID or employee ID number. | Private, Confidential |
| `amount` | This text contains a specific amount of money. | Confidential |
| `date` | This text contains a sensitive date such as a birth date. | Confidential |
| `reference` | This text contains a tracking, case or project reference code. | Confidential |
| `business` | This text contains a private company detail. | Confidential |
| `direction` | This text is something the user asked to hide: *(the typed direction)* | When a direction is typed |

## From answers to suggestions

For each OCR line:

1. Take the question with the highest probability.
2. If it is below `DECISION_THRESHOLD` (`0.5`), make no suggestion.
3. Otherwise propose that question's label (`other` for `direction`) with the probability as `confidence`.
4. Apply the evidence rules in [Labels](/docs/redact/reference/labels): the rule's label wins, and a line the rules don't support is dropped, except `name` and `other`.

The `decide()` call fails the analysis (`503 analyzer_unavailable`) if it returns a different number of results than lines.

## Copy check

Since lesson 11.

After **Done**, the browser sends each flattened page to `POST /v1/analyze-page` with the same level and direction.
Any suggestion returned is listed under **Still readable on the copy**.
It doesn't block **Save copy**.
If the service is busy, preparing the next document waits up to 60 s for it.
