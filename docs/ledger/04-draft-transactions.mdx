We will connect the real OCR reader to the service and turn its blocks into a draft transaction.
Every field in the draft points back to the OCR blocks it came from.
The draft never touches a balance.

**Source checkpoint:** `5eae853` · **Starting checkpoint:** `e7a734b`

## What changes

- `qvac-service/qvac-reader.ts`: a `ReceiptReader` backed by QVAC.
  It loads `OCR_LATIN` once, on the first request, and keeps it warm.
- `qvac-service/main.ts`: uses the QVAC reader and unloads it on shutdown.
- `src/features/ledger/draft-transactions.ts`: deterministic code that groups blocks into printed lines and pulls out merchant text, date, line items, subtotal, tax, and total.
- `src/features/ledger/receipt-inbox.tsx`: the "Receipt pocket" panel on the home page.
- `src/fixtures/corner-cafe-ocr.fixture.ts`: a **hand-written** fixture of OCR blocks, used only by tests.

To compare with the checkpoint: `git diff e7a734b 5eae853`.

## Build and observe

### 1. Connect the reader

Open `qvac-reader.ts`.
It follows the same order as the smoke script: write the config, set `QVAC_CONFIG_PATH`, then import the SDK.
`loadModel` runs once.
If two receipts arrive while it loads, both wait for the same promise.

For each receipt, the reader writes the bytes to a private temporary folder, calls `ocr` with that path, and deletes the folder in `finally`.
The receipt is never sent anywhere else.

Restart the service and check health:

```bash
npm run qvac:service
curl http://127.0.0.1:4318/health
```

The model ID is now `OCR_LATIN` and the state is `not_loaded`.
It changes to `loading`, then `ready`, after the first receipt.

### 2. Group blocks into printed lines

With `paragraph: false`, OCR often returns `TOTAL` and `10.53` as two blocks.
`groupRows` puts blocks on the same line together by comparing the vertical centre of their boxes.
Then it sorts each line left to right.

Each grouped line keeps the indexes of the blocks it used, and the lowest confidence among them.

### 3. Parse money as cents, and refuse to guess

`parseAmountCents("TOTAL 10.53")` returns `1053`.
Text without a clear two-decimal amount at the end returns `null`.
We never use floating point for money.

`draftFromOcr` then labels lines: a date, the `TOTAL`, `Subtotal`, `Tax`, and the remaining priced lines as items.
The first unpriced text line becomes the merchant text.
It is raw OCR text, not a cleaned-up merchant name.
Naming merchants is Chapter 5.

### 4. Let code check the receipt's own arithmetic

The draft records `totalMatchesSubtotalPlusTax`.
For the course receipt, 975 + 78 = 1053, so it is `true`.
If OCR misreads the total as `10.58`, it becomes `false`, and the panel says so.
A model never does this sum.

### 5. Read a receipt in the app

Start the app and the service in two terminals:

```bash
npm run qvac:service
npm run dev
```

Open `http://localhost:3000` and select **Read sample receipt**.

If the model is available on your machine, you will see a panel titled **Draft transaction (not in the ledger)**, with the block count, timing, the first 12 characters of the source digest, and evidence beside each field.

If the service is not running, or the model cannot load, you will see **Could not read receipt** and the real error.
That is the intended behaviour.

We could not complete a live model download while writing this course (see Chapter 2).
So the screenshots and numbers in our tests come from the hand-written fixture, not from QVAC.

### 6. Know what the fixture is

`corner-cafe-ocr.fixture.ts` is marked **HAND-WRITTEN FIXTURE**.
It copies the shape of real OCR blocks.
It splits amounts from labels and includes one bad read, `Croissamt` at confidence 0.62, so the tests do not assume perfect text.
The draft keeps `Croissamt` as it was read.
Correcting it is the reviewer's job, later.

```typescript
import { mkdir, mkdtemp, rm, writeFile } from "node:fs/promises";
import { tmpdir } from "node:os";
import path from "node:path";

import type { ModelState, OcrBlock } from "../src/features/ledger/receipt-contract.ts";
import { resolveLocalQvacPaths } from "./local-config.ts";
import type { ReceiptReader } from "./server.ts";

type Sdk = typeof import("@qvac/sdk");

// Loads OCR once, on first use, and keeps it warm for later receipts.
export function createQvacReader(appDirectory: string): ReceiptReader & { close(): Promise<void> } {
  const { cacheDirectory, configPath } = resolveLocalQvacPaths(appDirectory);
  let sdk: Sdk | undefined;
  let modelId: string | undefined;
  let state: ModelState["state"] = "not_loaded";
  let loading: Promise<string> | undefined;

  async function ensureModel(): Promise<string> {
    if (modelId) return modelId;
    loading ??= (async () => {
      state = "loading";
      await mkdir(cacheDirectory, { recursive: true });
      await writeFile(configPath, `${JSON.stringify({ cacheDirectory }, null, 2)}\n`, "utf8");
      process.env.QVAC_CONFIG_PATH = configPath;
      sdk = await import("@qvac/sdk");
      const id = await sdk.loadModel({ modelSrc: sdk.OCR_LATIN, modelConfig: { langList: ["en"] } });
      modelId = id;
      state = "ready";
      return id;
    })().catch((error: unknown) => {
      state = "error";
      loading = undefined;
      throw error;
    });
    return loading;
  }

  return {
    modelState: () => ({ kind: "ocr", id: "OCR_LATIN", state }),
    async read(png) {
      const id = await ensureModel();
      // Hand QVAC a private temporary file, then delete it after reading.
      const directory = await mkdtemp(path.join(tmpdir(), "ledger-receipt-"));
      const imagePath = path.join(directory, "receipt.png");
      let blocks, stats;
      try {
        await writeFile(imagePath, png);
        const run = sdk!.ocr({ modelId: id, image: imagePath, options: { paragraph: false } });
        [blocks, stats] = await Promise.all([run.blocks, run.stats]);
      } finally {
        await rm(directory, { recursive: true, force: true });
      }
      return {
        blocks: blocks.map(
          (block): OcrBlock => ({
            text: block.text,
            bbox: block.bbox ?? null,
            confidence: block.confidence ?? null,
          }),
        ),
        ocrMs: stats?.totalTime ?? null,
      };
    },
    async close() {
      if (sdk && modelId) {
        await sdk.unloadModel({ modelId, clearStorage: false }).catch(() => undefined);
      }
      if (sdk) await sdk.close().catch(() => undefined);
    },
  };
}

export const defaultAppDirectory = path.resolve(import.meta.dirname, "..");
```

```typescript
import type { OcrBlock } from "./receipt-contract";

// OCR text is evidence. This module turns it into a *draft* with provenance.
// It never posts anything to the ledger, and all money is integer cents.

export type Evidence<T> = {
  value: T;
  blockIndexes: number[];
  text: string;
  confidence: number | null;
};

export type DraftLine = { description: string; amountCents: number; evidence: Evidence<number> };

export type DraftTransaction = {
  id: string;
  receiptId: string;
  sourceDigest: string;
  status: "draft";
  merchant: Evidence<string> | null;
  date: Evidence<string> | null;
  totalCents: Evidence<number> | null;
  subtotalCents: Evidence<number> | null;
  taxCents: Evidence<number> | null;
  lines: DraftLine[];
  checks: { totalMatchesSubtotalPlusTax: boolean | null };
};

type Row = { text: string; blockIndexes: number[]; confidence: number | null };

/** Group OCR blocks that sit on the same printed line, left to right. */
export function groupRows(blocks: OcrBlock[]): Row[] {
  const items = blocks.map((block, index) => ({ block, index }));
  const placed = items.filter((i) => i.block.bbox !== null);
  const loose = items.filter((i) => i.block.bbox === null);
  placed.sort((a, b) => center(a.block) - center(b.block));

  const rows: { members: typeof items; center: number; height: number }[] = [];
  for (const item of placed) {
    const [, y1, , y2] = item.block.bbox!;
    const row = rows.at(-1);
    if (row && Math.abs(center(item.block) - row.center) <= row.height / 2) {
      row.members.push(item);
    } else {
      rows.push({ members: [item], center: center(item.block), height: Math.max(1, y2 - y1) });
    }
  }
  const grouped = rows.map((row) => row.members.sort((a, b) => a.block.bbox![0] - b.block.bbox![0]));
  return [...grouped, ...loose.map((i) => [i])].map((members) => ({
    text: members.map((m) => m.block.text.trim()).join(" ").replace(/\s+/g, " "),
    blockIndexes: members.map((m) => m.index),
    confidence: minConfidence(members.map((m) => m.block.confidence)),
  }));
}

function center(block: OcrBlock) {
  const [, y1, , y2] = block.bbox!;
  return (y1 + y2) / 2;
}

function minConfidence(values: (number | null)[]): number | null {
  const known = values.filter((v): v is number => v !== null);
  return known.length === values.length && known.length > 0 ? Math.min(...known) : null;
}

const AMOUNT_AT_END = /(-?\d{1,6})[.,](\d{2})\s*$/;

/** "10.53" -> 1053. Returns null instead of guessing. */
export function parseAmountCents(text: string): number | null {
  const match = AMOUNT_AT_END.exec(text.trim());
  if (!match) return null;
  const whole = Number.parseInt(match[1], 10);
  const cents = Number.parseInt(match[2], 10);
  return whole < 0 || match[1].startsWith("-") ? -(Math.abs(whole) * 100 + cents) : whole * 100 + cents;
}

const DATE = /(\d{4})-(\d{2})-(\d{2})/;
const SKIP_DESCRIPTION = /^(paid|card|change|cash)\b/i;

function evidence<T>(value: T, row: Row): Evidence<T> {
  return { value, blockIndexes: row.blockIndexes, text: row.text, confidence: row.confidence };
}

export function draftFromOcr(input: {
  receiptId: string;
  sourceDigest: string;
  blocks: OcrBlock[];
}): DraftTransaction {
  const rows = groupRows(input.blocks).filter((row) => row.text.length > 0);
  let merchant: Evidence<string> | null = null;
  let date: Evidence<string> | null = null;
  let totalCents: Evidence<number> | null = null;
  let subtotalCents: Evidence<number> | null = null;
  let taxCents: Evidence<number> | null = null;
  const lines: DraftLine[] = [];

  for (const row of rows) {
    const amount = parseAmountCents(row.text);
    const label = row.text.replace(AMOUNT_AT_END, "").trim();
    const dateMatch = DATE.exec(row.text);

    if (!date && dateMatch) {
      date = evidence(dateMatch[0], row);
    } else if (amount !== null && /^total\b/i.test(label)) {
      totalCents = evidence(amount, row);
    } else if (amount !== null && /^sub\s?total\b/i.test(label)) {
      subtotalCents = evidence(amount, row);
    } else if (amount !== null && /^(tax|vat)\b/i.test(label)) {
      taxCents = evidence(amount, row);
    } else if (amount !== null && label && !SKIP_DESCRIPTION.test(label)) {
      lines.push({ description: label, amountCents: amount, evidence: evidence(amount, row) });
    } else if (!merchant && amount === null && /[a-z]/i.test(row.text)) {
      merchant = evidence(row.text, row);
    }
  }

  const totalMatchesSubtotalPlusTax =
    totalCents && subtotalCents && taxCents
      ? subtotalCents.value + taxCents.value === totalCents.value
      : null;

  return {
    id: `draft-${input.receiptId}`,
    receiptId: input.receiptId,
    sourceDigest: input.sourceDigest,
    status: "draft",
    merchant,
    date,
    totalCents,
    subtotalCents,
    taxCents,
    lines,
    checks: { totalMatchesSubtotalPlusTax },
  };
}

export function formatCents(cents: number): string {
  const sign = cents < 0 ? "-" : "";
  const abs = Math.abs(cents);
  return `${sign}${Math.floor(abs / 100)}.${String(abs % 100).padStart(2, "0")}`;
}
```

```tsx
"use client";

import { useState } from "react";

import { draftFromOcr, formatCents, type DraftTransaction, type Evidence } from "./draft-transactions";
import { createReceiptClient, type ReceiptClient } from "./receipt-client";

const SAMPLE_URL = "/test-files/ledger/receipt-corner-cafe.png";

type Status =
  | { kind: "idle" }
  | { kind: "reading" }
  | { kind: "error"; message: string }
  | { kind: "ready"; draft: DraftTransaction; ocrMs: number | null; blockCount: number };

function Source({ evidence }: { evidence: Evidence<unknown> | null }) {
  if (!evidence) return <span>not found</span>;
  const confidence = evidence.confidence === null ? "n/a" : evidence.confidence.toFixed(2);
  return (
    <small>
      from blocks {evidence.blockIndexes.join(", ")}: “{evidence.text}” · confidence {confidence}
    </small>
  );
}

export function ReceiptInbox({ client }: { client?: ReceiptClient }) {
  const [status, setStatus] = useState<Status>({ kind: "idle" });

  async function read(fileName: string, bytes: ArrayBuffer) {
    setStatus({ kind: "reading" });
    try {
      const api = client ?? createReceiptClient();
      const receiptId = `${Date.now()}`;
      const result = await api.readReceipt({ receiptId, fileName, pngBytes: bytes });
      setStatus({
        kind: "ready",
        draft: draftFromOcr({
          receiptId: result.receiptId,
          sourceDigest: result.sourceDigest,
          blocks: result.blocks,
        }),
        ocrMs: result.ocrMs,
        blockCount: result.blocks.length,
      });
    } catch (error) {
      setStatus({ kind: "error", message: error instanceof Error ? error.message : String(error) });
    }
  }

  async function readSample() {
    const response = await fetch(SAMPLE_URL);
    await read("receipt-corner-cafe.png", await response.arrayBuffer());
  }

  return (
    <section aria-labelledby="receipt-inbox">
      <h2 id="receipt-inbox">Receipt pocket</h2>
      <p>Receipts are read on this computer. Results are drafts and never change your balances.</p>
      <label>
        Receipt image (PNG)
        <input
          type="file"
          accept="image/png"
          onChange={async (event) => {
            const file = event.target.files?.[0];
            if (file) await read(file.name, await file.arrayBuffer());
          }}
        />
      </label>
      <button type="button" onClick={readSample} disabled={status.kind === "reading"}>
        Read sample receipt
      </button>

      {status.kind === "reading" && <p role="status">Reading receipt locally…</p>}
      {status.kind === "error" && <p role="alert">Could not read receipt: {status.message}</p>}
      {status.kind === "ready" && (
        <article aria-label="Draft transaction">
          <h3>Draft transaction (not in the ledger)</h3>
          <p>
            {status.blockCount} OCR blocks · {status.ocrMs === null ? "time unknown" : `${status.ocrMs} ms`} · source{" "}
            <code>{status.draft.sourceDigest.slice(0, 12)}</code>
          </p>
          <dl>
            <dt>Merchant text</dt>
            <dd>
              {status.draft.merchant?.value ?? "—"} <Source evidence={status.draft.merchant} />
            </dd>
            <dt>Date</dt>
            <dd>
              {status.draft.date?.value ?? "—"} <Source evidence={status.draft.date} />
            </dd>
            <dt>Printed total</dt>
            <dd>
              {status.draft.totalCents ? formatCents(status.draft.totalCents.value) : "—"}{" "}
              <Source evidence={status.draft.totalCents} />
            </dd>
          </dl>
          <p>
            Arithmetic check:{" "}
            {status.draft.checks.totalMatchesSubtotalPlusTax === null
              ? "not enough evidence"
              : status.draft.checks.totalMatchesSubtotalPlusTax
                ? "subtotal + tax equals total"
                : "subtotal + tax does NOT equal total, review the amounts"}
          </p>
          <table>
            <thead>
              <tr>
                <th>Line</th>
                <th>Amount</th>
                <th>Evidence</th>
              </tr>
            </thead>
            <tbody>
              {status.draft.lines.map((line) => (
                <tr key={line.evidence.blockIndexes.join("-")}>
                  <td>{line.description}</td>
                  <td>{formatCents(line.amountCents)}</td>
                  <td>
                    <Source evidence={line.evidence} />
                  </td>
                </tr>
              ))}
            </tbody>
          </table>
        </article>
      )}
    </section>
  );
}
```

```typescript
import { describe, expect, it } from "vitest";

import { cornerCafeOcrFixture } from "@/fixtures/corner-cafe-ocr.fixture";

import { draftFromOcr, formatCents, groupRows, parseAmountCents } from "./draft-transactions";

const draft = () =>
  draftFromOcr({ receiptId: "r1", sourceDigest: "digest", blocks: cornerCafeOcrFixture });

describe("draft transactions from OCR evidence (hand-written fixture)", () => {
  it("joins label and amount blocks that share a printed line", () => {
    const rows = groupRows(cornerCafeOcrFixture);
    expect(rows.map((r) => r.text)).toContain("TOTAL 10.53");
    expect(rows.find((r) => r.text === "TOTAL 10.53")?.blockIndexes).toEqual([13, 14]);
  });

  it("parses money as integer cents and refuses to guess", () => {
    expect(parseAmountCents("TOTAL 10.53")).toBe(1053);
    expect(parseAmountCents("Tax 0,78")).toBe(78);
    expect(parseAmountCents("TOTAL ten")).toBeNull();
    expect(formatCents(1053)).toBe("10.53");
  });

  it("produces a draft with provenance for every field", () => {
    const result = draft();

    expect(result.status).toBe("draft");
    expect(result.merchant?.value).toBe("CORNER CAFE");
    expect(result.date?.value).toBe("2026-03-14");
    expect(result.totalCents?.value).toBe(1053);
    expect(result.totalCents?.blockIndexes).toEqual([13, 14]);
    expect(result.lines.map((l) => [l.description, l.amountCents])).toEqual([
      ["Flat white", 450],
      ["Croissamt", 325],
      ["Sparkling water", 200],
    ]);
  });

  it("keeps the low-confidence OCR text as evidence instead of correcting it", () => {
    const croissant = draft().lines[1];
    expect(croissant.description).toBe("Croissamt");
    expect(croissant.evidence.confidence).toBe(0.62);
  });

  it("checks the receipt's own arithmetic in code", () => {
    expect(draft().checks.totalMatchesSubtotalPlusTax).toBe(true);

    const misread = cornerCafeOcrFixture.map((b) => (b.text === "10.53" ? { ...b, text: "10.58" } : b));
    const bad = draftFromOcr({ receiptId: "r2", sourceDigest: "d", blocks: misread });
    expect(bad.checks.totalMatchesSubtotalPlusTax).toBe(false);
  });

  it("returns empty fields, not invented ones, when OCR finds nothing", () => {
    const empty = draftFromOcr({ receiptId: "r3", sourceDigest: "d", blocks: [] });
    expect(empty.merchant).toBeNull();
    expect(empty.totalCents).toBeNull();
    expect(empty.checks.totalMatchesSubtotalPlusTax).toBeNull();
  });
});
```
