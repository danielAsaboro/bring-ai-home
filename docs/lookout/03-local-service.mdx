We will put a small HTTP service between the browser and QVAC.
React never imports QVAC.
The native runtime lives in its own Node process on `127.0.0.1`.

At the end of this chapter health works, bad requests are rejected, and with vision switched off a frame check answers a typed `503`.
That is a correct result.
Lookout never invents a verdict.

**Source checkpoint:** `702516e` · **Starting checkpoint:** `b11ed2b`

## What changes

| File | Responsibility |
| --- | --- |
| `src/features/lookout/check-contract.ts` | Request and response shapes with hand-written validation |
| `src/features/lookout/check-client.ts` | Browser client that returns typed failures |
| `qvac-service/server.ts` | The HTTP server. It takes a `FrameChecker` as a parameter |
| `qvac-service/qvac-checker.ts` | The QVAC `FrameChecker`: SmolVLM2, loaded on first use |
| `qvac-service/serve.mjs` | Starts the server on `127.0.0.1:4319` |
| `tsconfig.json` | `allowImportingTsExtensions`, so Node can run the `.ts` files directly |

To compare with the starting checkpoint: `git diff b11ed2b 702516e`.

## Build and observe

### 1. Define the contract

Read `check-contract.ts`.
A request carries a frame ID, a condition, and the PNG as base64.
It never carries a file path.
A response carries the SHA-256 of the bytes the service received, the model name, the raw reply, the parsed verdict, and the time taken.

TypeScript types vanish at runtime, so both sides validate with plain functions.

### 2. Start the boundary without a model

```bash
git checkout 702516e
LOOKOUT_VISION=off npm run qvac:service
```

In another terminal:

```bash
curl http://127.0.0.1:4319/health
curl -X POST http://127.0.0.1:4319/v1/check-frame \
  -d '{"frameId":"front-gate-3","condition":"a parcel is left by the gate","pngBase64":"aGk="}'
```

We ran exactly this in our build container.
The output was:

```json
{"service":"ready","vision":{"state":"not_configured"}}
{"error":{"code":"vision_unavailable","message":"The local vision model is not configured"}}
```

The process is ready.
The model is not.
Those are different things.

### 3. Start it with QVAC

Stop the service and run `npm run qvac:service`.
Now `health` reports the vision model as `configured`.
It loads on the first check, not at startup.
Send the same `curl` with a real base64 PNG and you get the digest, raw reply, and verdict.

### 4. Check the local boundary

The service binds to `127.0.0.1` only.
Browser requests from any origin other than `localhost`, `127.0.0.1`, or `[::1]` get `403`.
A random website cannot ask your service about your frames.

This is not authentication.
Other software on your machine can still call it.

### 5. Read the client

Open `check-client.ts`.
A refused connection is `unavailable`.
A `503` is `unavailable`.
A response that fails validation is `invalid`.
The caller always knows which boundary failed.

```typescript
import { mkdir, rm, writeFile } from "node:fs/promises";
import { createHash } from "node:crypto";
import path from "node:path";

import type { FrameChecker } from "./server.ts";

type Sdk = typeof import("@qvac/sdk");

export const VISION_MODEL = "SMOLVLM2_500M_MULTIMODAL_Q8_0";

// SmolVLM2 with its projection model. Loaded on first use, kept warm afterwards.
// Extra modelConfig (lesson 07) is passed straight to loadModel.
export function createQvacChecker(
  appDirectory: string,
  extraModelConfig: Record<string, string> = {},
): FrameChecker & { close(): Promise<void> } {
  const framesDirectory = path.join(appDirectory, ".qvac", "frames");
  let sdk: Sdk | undefined;
  let loading: Promise<string> | undefined;

  function ensureModel() {
    loading ??= (async () => {
      sdk = await import("@qvac/sdk");
      return sdk.loadModel({
        modelSrc: sdk.SMOLVLM2_500M_MULTIMODAL_Q8_0,
        modelConfig: {
          ctx_size: 1024,
          projectionModelSrc: sdk.MMPROJ_SMOLVLM2_500M_MULTIMODAL_Q8_0,
          ...extraModelConfig,
        },
      });
    })().catch((error: unknown) => {
      loading = undefined;
      throw error;
    });
    return loading;
  }

  return {
    model: VISION_MODEL,
    async check(png, prompt) {
      const modelId = await ensureModel();
      // Attachments are file paths. The frame is written to this machine's disk,
      // read by the local model, and deleted.
      await mkdir(framesDirectory, { recursive: true });
      const framePath = path.join(framesDirectory, `${createHash("sha256").update(png).digest("hex")}.png`);
      await writeFile(framePath, png);
      try {
        const run = sdk!.completion({
          modelId,
          history: [{ role: "user", content: prompt, attachments: [{ path: framePath }] }],
          stream: true,
        });
        let raw = "";
        for await (const token of run.tokenStream) raw += token;
        return raw;
      } finally {
        await rm(framePath, { force: true });
      }
    },
    async close() {
      if (sdk && loading) {
        const modelId = await loading.catch(() => undefined);
        if (modelId) await sdk.unloadModel({ modelId, clearStorage: false }).catch(() => undefined);
      }
      if (sdk) await sdk.close().catch(() => undefined);
    },
  };
}
```

```javascript
import { mkdir, writeFile } from "node:fs/promises";
import path from "node:path";
import { fileURLToPath } from "node:url";

const appDirectory = fileURLToPath(new URL("../", import.meta.url));
const qvacDirectory = path.join(appDirectory, ".qvac");
const cacheDirectory = path.join(qvacDirectory, "models");
const configPath = path.join(qvacDirectory, "config.json");

const { createLookoutServer, SERVICE_PORT } = await import("./server.ts");
const { createQvacChecker } = await import("./qvac-checker.ts");

await mkdir(cacheDirectory, { recursive: true });
await writeFile(configPath, `${JSON.stringify({ cacheDirectory }, null, 2)}\n`, "utf8");
process.env.QVAC_CONFIG_PATH = configPath;

// LOOKOUT_VISION=off starts the boundary without a model, to see the 503 path.
const checker = process.env.LOOKOUT_VISION === "off" ? null : createQvacChecker(appDirectory);
const server = createLookoutServer({ checker });
server.listen(SERVICE_PORT, "127.0.0.1", () => {
  process.stderr.write(`Lookout QVAC service on http://127.0.0.1:${SERVICE_PORT}\n`);
});

async function shutdown() {
  server.close();
  await checker?.close();
  process.exit(0);
}
process.on("SIGINT", shutdown);
process.on("SIGTERM", shutdown);
```

```typescript
import { createHash } from "node:crypto";
import { createServer, type IncomingMessage, type ServerResponse } from "node:http";

import { parseCheckFrameRequest } from "../src/features/lookout/check-contract.ts";
import { buildConditionPrompt, parseVerdict } from "../src/features/lookout/verdict.ts";

export const SERVICE_PORT = 4319;
const MAX_BODY_BYTES = 2_100_000;

// The only thing the server knows about inference. QVAC lives behind it.
export type FrameChecker = {
  model: string;
  check(png: Buffer, prompt: string): Promise<string>;
};

export function isAllowedOrigin(origin: string | undefined): boolean {
  if (!origin) return true; // curl and local scripts send no Origin
  try {
    const url = new URL(origin);
    return url.protocol === "http:" && ["localhost", "127.0.0.1", "[::1]"].includes(url.hostname);
  } catch {
    return false;
  }
}

function send(res: ServerResponse, status: number, body: unknown, origin?: string) {
  res.writeHead(status, {
    "content-type": "application/json",
    ...(origin ? { "access-control-allow-origin": origin, vary: "Origin" } : {}),
    "access-control-allow-headers": "content-type",
    "access-control-allow-methods": "GET, POST, OPTIONS",
  });
  res.end(JSON.stringify(body));
}

function fail(res: ServerResponse, status: number, code: string, message: string, origin?: string) {
  send(res, status, { error: { code, message } }, origin);
}

async function readJson(req: IncomingMessage): Promise<unknown> {
  let size = 0;
  const chunks: Buffer[] = [];
  for await (const chunk of req) {
    size += (chunk as Buffer).length;
    if (size > MAX_BODY_BYTES) throw new Error("too_large");
    chunks.push(chunk as Buffer);
  }
  return JSON.parse(Buffer.concat(chunks).toString("utf8"));
}

export function createLookoutServer({ checker }: { checker: FrameChecker | null }) {
  return createServer(async (req, res) => {
    const origin = req.headers.origin;
    if (!isAllowedOrigin(origin)) return fail(res, 403, "origin_denied", "Only local pages may call Lookout's service");
    if (req.method === "OPTIONS") return send(res, 204, null, origin);

    if (req.method === "GET" && req.url === "/health") {
      return send(
        res,
        200,
        { service: "ready", vision: checker ? { model: checker.model, state: "configured" } : { state: "not_configured" } },
        origin,
      );
    }

    if (req.method === "POST" && req.url === "/v1/check-frame") {
      let body: unknown;
      try {
        body = await readJson(req);
      } catch (error) {
        const tooLarge = error instanceof Error && error.message === "too_large";
        return fail(res, tooLarge ? 413 : 400, tooLarge ? "too_large" : "bad_json", tooLarge ? "Frame is too large" : "Body must be JSON", origin);
      }
      const parsed = parseCheckFrameRequest(body);
      if (!parsed.ok) return fail(res, 400, "bad_request", parsed.message, origin);
      let prompt: string;
      try {
        prompt = buildConditionPrompt(parsed.value.condition);
      } catch (error) {
        return fail(res, 400, "bad_condition", (error as Error).message, origin);
      }
      if (!checker) return fail(res, 503, "vision_unavailable", "The local vision model is not configured", origin);

      const png = Buffer.from(parsed.value.pngBase64, "base64");
      const frameDigest = createHash("sha256").update(png).digest("hex");
      const startedAt = Date.now();
      try {
        const raw = await checker.check(png, prompt);
        return send(
          res,
          200,
          { frameId: parsed.value.frameId, frameDigest, model: checker.model, raw, verdict: parseVerdict(raw), ms: Date.now() - startedAt },
          origin,
        );
      } catch (error) {
        return fail(res, 503, "vision_failed", error instanceof Error ? error.message : "Vision check failed", origin);
      }
    }

    return fail(res, 404, "not_found", "Unknown route", origin);
  });
}
```

```typescript
import { parseCheckFrameResponse, SERVICE_URL, type CheckFrameResponse } from "./check-contract";
import type { Frame } from "./sources";

export type CheckOutcome =
  | { ok: true; value: CheckFrameResponse }
  | { ok: false; kind: "unavailable" | "rejected" | "invalid"; message: string };

function toBase64(bytes: ArrayBuffer): string {
  let binary = "";
  const view = new Uint8Array(bytes);
  for (let i = 0; i < view.length; i += 1) binary += String.fromCharCode(view[i]);
  return btoa(binary);
}

// Sends one stored frame to the local service. Every failure comes back typed;
// the caller never has to guess, and never invents a verdict.
export async function checkFrame(
  frame: Frame,
  condition: string,
  fetchImpl: typeof fetch = fetch,
  serviceUrl = SERVICE_URL,
): Promise<CheckOutcome> {
  let response: Response;
  try {
    const image = await fetchImpl(frame.image);
    const pngBase64 = toBase64(await image.arrayBuffer());
    response = await fetchImpl(`${serviceUrl}/v1/check-frame`, {
      method: "POST",
      headers: { "content-type": "application/json" },
      body: JSON.stringify({ frameId: frame.id, condition, pngBase64 }),
    });
  } catch {
    return { ok: false, kind: "unavailable", message: "The local QVAC service is not running" };
  }
  const body: unknown = await response.json().catch(() => null);
  if (!response.ok) {
    const message =
      (body as { error?: { message?: string } } | null)?.error?.message ?? `Service answered ${response.status}`;
    return { ok: false, kind: response.status === 503 ? "unavailable" : "rejected", message };
  }
  const parsed = parseCheckFrameResponse(body);
  return parsed.ok ? parsed : { ok: false, kind: "invalid", message: parsed.message };
}
```

```typescript
// The HTTP contract between the Lookout UI and the local QVAC service.
// JSON from another process can be anything, so both sides validate by hand.
import type { Verdict } from "./verdict";

export const SERVICE_URL = "http://127.0.0.1:4319";
export const MAX_PNG_BASE64_LENGTH = 2_000_000;

export type CheckFrameRequest = { frameId: string; condition: string; pngBase64: string };

export type CheckFrameResponse = {
  frameId: string;
  frameDigest: string;
  model: string;
  raw: string;
  verdict: Verdict;
  ms: number;
};

export type Result<T> = { ok: true; value: T } | { ok: false; message: string };

function isRecord(v: unknown): v is Record<string, unknown> {
  return typeof v === "object" && v !== null && !Array.isArray(v);
}

function isText(v: unknown): v is string {
  return typeof v === "string" && v.trim().length > 0;
}

export function parseCheckFrameRequest(value: unknown): Result<CheckFrameRequest> {
  if (!isRecord(value)) return { ok: false, message: "Request body must be a JSON object" };
  const { frameId, condition, pngBase64 } = value;
  if (!isText(frameId)) return { ok: false, message: "frameId is required" };
  if (!isText(condition)) return { ok: false, message: "condition is required" };
  if (!isText(pngBase64)) return { ok: false, message: "pngBase64 is required" };
  if (pngBase64.length > MAX_PNG_BASE64_LENGTH) return { ok: false, message: "Frame is too large" };
  return { ok: true, value: { frameId, condition, pngBase64 } };
}

export function parseCheckFrameResponse(value: unknown): Result<CheckFrameResponse> {
  if (!isRecord(value)) return { ok: false, message: "Response must be a JSON object" };
  const { frameId, frameDigest, model, raw, verdict, ms } = value;
  if (!isText(frameId) || !isText(frameDigest) || !isText(model) || typeof raw !== "string") {
    return { ok: false, message: "Response is missing frame, digest, model, or raw text" };
  }
  if (typeof ms !== "number" || !isRecord(verdict)) return { ok: false, message: "Response is missing verdict" };
  const { answer, reason } = verdict;
  if ((answer !== "yes" && answer !== "no" && answer !== "unclear") || typeof reason !== "string") {
    return { ok: false, message: "Verdict must be yes, no, or unclear" };
  }
  return { ok: true, value: { frameId, frameDigest, model, raw, verdict: { answer, reason }, ms } };
}
```
