We will ask a local vision model one question about one stored frame: does it show "a parcel left by the gate"? The script runs outside the app. React does not change in this chapter.

The model proposes an answer. A small parser decides what Lookout will believe: a leading YES or NO, or **unclear**.

## Build and observe

### 1. Install

```bash
git checkout b11ed2b
npm ci
```

On Linux, check that the Bare binary is executable. If `ls -l node_modules/bare-runtime-linux-x64/bin/bare` shows no `x`, run `chmod +x` on it. That is an install problem, not a model problem.

`b4a` is a direct dependency because the SDK needs it at runtime on Linux.

### 2. Read the order of operations

Open `qvac-service/check-frame-smoke.mjs`. It creates `.qvac/models`, writes `.qvac/config.json`, sets `QVAC_CONFIG_PATH`, and only then imports `@qvac/sdk`. The SDK reads its config when it starts.

`loadModel` loads `SMOLVLM2_500M_MULTIMODAL_Q8_0` with `projectionModelSrc: MMPROJ_SMOLVLM2_500M_MULTIMODAL_Q8_0`. The projection model lets the language model read an image. `completion` sends the prompt with `attachments: [{ path }]`. The `finally` block unloads the model and closes the SDK, even after an error.

### 3. Run it

```bash
npm run qvac:check-smoke
npm run qvac:check-smoke -- public/test-files/lookout/front-gate-4.png "a parcel left by the gate"
```

The first run downloads model files into `.qvac/models`. Read `raw`, then `verdict`. `raw` is exactly what the model said. `verdict` is what Lookout will believe. Run the cat frame too. A small model may say yes to the wrong frame; that is why it only proposes.

We did not record a live run for this page. In our build container the QVAC registry is blocked, so no model output is shown here. Record your own receipt on your machine.

### 4. Read the parser

Open `verdict.ts`. A reply counts only if it starts with YES or NO. "It might be a parcel, yes" is **unclear**. "Yesterday a box was here" is **unclear**, because `\b` stops "yes" from matching inside "Yesterday". Unclear never raises an alert on its own.

### 5. If the download stalls

QVAC fetches models from its own registry, not from npm. If the log stops at a download line and the files stay at 0 bytes, the network is blocking the registry. That is a network failure. Run on a machine with normal internet. Do not change the code.

<Accordion title="qvac-service/check-frame-smoke.mjs">

```javascript
// Ask a local vision model whether one stored frame shows a plain-language condition.
// Usage: npm run qvac:check-smoke -- [frame.png] ["condition"]
import { createHash } from "node:crypto";
import { access, mkdir, readFile, writeFile } from "node:fs/promises";
import path from "node:path";
import { fileURLToPath } from "node:url";

const { buildConditionPrompt, parseVerdict } = await import("../src/features/lookout/verdict.ts");

const appDirectory = fileURLToPath(new URL("../", import.meta.url));
const defaultFrame = path.join(appDirectory, "public/test-files/lookout/front-gate-3.png");
const framePath = path.resolve(process.argv[2] ?? defaultFrame);
const condition = process.argv[3] ?? "a parcel is left by the gate";
const qvacDirectory = path.join(appDirectory, ".qvac");
const cacheDirectory = path.join(qvacDirectory, "models");
const configPath = path.join(qvacDirectory, "config.json");
const modelName = "SMOLVLM2_500M_MULTIMODAL_Q8_0";

let sdk;
let modelId;
try {
  await access(framePath);
  const prompt = buildConditionPrompt(condition);
  const frameDigest = createHash("sha256").update(await readFile(framePath)).digest("hex");

  // The SDK reads its config when it starts, so write it before the import.
  await mkdir(cacheDirectory, { recursive: true });
  await writeFile(configPath, `${JSON.stringify({ cacheDirectory }, null, 2)}\n`, "utf8");
  process.env.QVAC_CONFIG_PATH = configPath;

  sdk = await import("@qvac/sdk");
  modelId = await sdk.loadModel({
    modelSrc: sdk.SMOLVLM2_500M_MULTIMODAL_Q8_0,
    modelConfig: { ctx_size: 1024, projectionModelSrc: sdk.MMPROJ_SMOLVLM2_500M_MULTIMODAL_Q8_0 },
    onProgress: (p) => process.stderr.write(`Downloading ${p.percentage.toFixed(0)}%\n`),
  });
  const startedAt = Date.now();
  const run = sdk.completion({
    modelId,
    history: [{ role: "user", content: prompt, attachments: [{ path: framePath }] }],
    stream: true,
  });
  let raw = "";
  for await (const token of run.tokenStream) raw += token;
  process.stdout.write(
    `${JSON.stringify(
      {
        kind: "proposed-verdict",
        frame: path.basename(framePath),
        frameDigest,
        condition,
        model: modelName,
        raw,
        verdict: parseVerdict(raw),
        elapsedMs: Date.now() - startedAt,
      },
      null,
      2,
    )}\n`,
  );
} catch (error) {
  const message = error instanceof Error ? error.message : String(error);
  process.stderr.write(
    `QVAC frame check failed: ${message}\nThe first run downloads model files into ${cacheDirectory}. A stalled download is a network problem, not a code problem.\n`,
  );
  process.exitCode = 1;
} finally {
  if (sdk && modelId) await sdk.unloadModel({ modelId, clearStorage: false }).catch(() => undefined);
  if (sdk) await sdk.close().catch(() => undefined);
}
```

```typescript
import { describe, expect, it } from "vitest";

import { buildConditionPrompt, parseVerdict } from "./verdict";

// Hand-written model replies (fixtures). They are not live model output.
describe("parseVerdict", () => {
  it("reads a leading yes or no", () => {
    expect(parseVerdict("YES. A brown box sits by the gate.")).toEqual({
      answer: "yes",
      reason: "A brown box sits by the gate.",
    });
    expect(parseVerdict(" no - the path is empty")).toEqual({ answer: "no", reason: "the path is empty" });
  });

  it("treats hedges and buried answers as unclear", () => {
    expect(parseVerdict("It might be a parcel, yes").answer).toBe("unclear");
    expect(parseVerdict("Yesterday a box was here").answer).toBe("unclear");
    expect(parseVerdict("").answer).toBe("unclear");
  });
});

describe("buildConditionPrompt", () => {
  it("rejects empty and overlong conditions", () => {
    expect(() => buildConditionPrompt("   ")).toThrow("Write a condition first");
    expect(() => buildConditionPrompt("x".repeat(121))).toThrow("under 120");
    expect(buildConditionPrompt("a parcel is left by the gate")).toContain("Condition: a parcel is left by the gate");
  });
});
```

```typescript
// A model's answer to "does this frame show <condition>?".
// The model proposes; this parser decides what Lookout will believe.

export type Verdict = {
  answer: "yes" | "no" | "unclear";
  reason: string;
};

export const MAX_CONDITION_LENGTH = 120;

export function buildConditionPrompt(condition: string): string {
  const clean = condition.replace(/\s+/g, " ").trim();
  if (!clean) throw new Error("Write a condition first");
  if (clean.length > MAX_CONDITION_LENGTH) throw new Error("Keep the condition under 120 characters");
  return (
    `Condition: ${clean}\n` +
    "Look only at this still frame. Does it show the condition? " +
    "Start your reply with exactly YES or NO, then give one short reason based on what is visible."
  );
}

// Anything that does not start with a clear yes or no is "unclear".
// Unclear never raises an alert on its own.
export function parseVerdict(raw: string): Verdict {
  const text = raw.replace(/\s+/g, " ").trim();
  const match = /^\W*(yes|no)\b[\s.,:;!-]*(.*)$/i.exec(text);
  if (!match) return { answer: "unclear", reason: text.slice(0, 200) };
  return {
    answer: match[1].toLowerCase() as "yes" | "no",
    reason: match[2].slice(0, 200),
  };
}
```
