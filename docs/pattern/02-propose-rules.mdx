We will add the pinned QVAC SDK and ask a local model to propose a weave from three examples, outside the app.

Typing rules works, but you already know what you want: you have the before and after values. A local language model can read those examples and propose rules.

We start beside the app, not inside it. A standalone script loads `LLAMA_3_2_1B_INST_Q4_0`, sends one pattern's examples, and prints the raw reply. Downloads, the native runtime, and the prompt are easier to diagnose here than behind React.

## Build and observe

### 1. Install the pinned SDK

```bash
git checkout f06cb75
npm ci
```

On Linux, if the native runtime will not start, run `chmod +x node_modules/bare-runtime-linux-x64/bin/bare`.

### 2. Run one proposal

```bash
npm run qvac:propose-smoke -- p-contacts
```

The first run downloads the model into `.qvac/models` inside the app (ignored by git). The output has `raw` (exactly what the model said), `candidate` (the JSON array found in it, still untrusted), and `parseError` if there was none.

### 3. Classify the failure before fixing it

If the script stalls with no `Downloading` lines, or leaves a zero-byte `.gguf` in `.qvac/models`, that is a network or download failure, not a code or model failure. Fix the network and run it again.

Our build container blocks model downloads. There the script left a zero-byte Llama file and never reached inference, so this lesson shows no model output. Your own run is the receipt.

### 4. Read what the model is told

Open `qvac-service/proposal.ts`. The system prompt lists the five rule shapes and asks for JSON only. Notice what we have not done yet: nothing checks that the reply is a valid rule.

<Accordion title="qvac-service/proposal.ts">

```typescript
import type { Example } from "../src/features/pattern/patterns.ts";

export type ChatMessage = { role: "system" | "user" | "assistant"; content: string };

export const PROPOSAL_SYSTEM_PROMPT = [
  "You turn before/after text examples into an ordered list of transformation rules.",
  "Reply with only a JSON array. Each item is one of:",
  '{"kind":"trim","collapse":true}',
  '{"kind":"split","separator":",","order":[1,0],"join":" "}  (order lists zero-based parts to keep)',
  '{"kind":"case","to":"upper"|"lower"|"title"}',
  '{"kind":"replace","find":"text","with":"text"}  (literal text, not a regular expression)',
  '{"kind":"format","template":"prefix {value} suffix"}',
  "Use as few rules as possible. Do not explain.",
].join("\n");

export function formatExamples(examples: readonly Pick<Example, "before" | "after">[]): string {
  return examples
    .map((e, i) => `Example ${i + 1}\nbefore: ${JSON.stringify(e.before)}\nafter: ${JSON.stringify(e.after)}`)
    .join("\n\n");
}

export function buildProposalHistory(examples: readonly Pick<Example, "before" | "after">[]): ChatMessage[] {
  if (examples.length === 0) throw new Error("A proposal needs at least one example");
  return [
    { role: "system", content: PROPOSAL_SYSTEM_PROMPT },
    { role: "user", content: formatExamples(examples) },
  ];
}

// Lesson 02 keeps this loose on purpose: find the JSON array and return it untrusted.
export function extractProposal(raw: string): unknown[] {
  const start = raw.indexOf("[");
  const end = raw.lastIndexOf("]");
  if (start === -1 || end <= start) throw new Error("The model reply contains no JSON array");
  const parsed: unknown = JSON.parse(raw.slice(start, end + 1));
  if (!Array.isArray(parsed)) throw new Error("The model reply is not a JSON array");
  return parsed;
}
```

<Accordion title="qvac-service/propose-smoke.mjs">

```javascript
// Run one real local proposal for a saved sample pattern and print the raw reply.
import { fileURLToPath } from "node:url";

const appDirectory = fileURLToPath(new URL("../", import.meta.url));
const patternId = process.argv[2] ?? "p-contacts";

const runtime = await import("./qvac-runtime.ts");
const { buildProposalHistory, extractProposal } = await import("./proposal.ts");
const { samplePatterns } = await import("../src/features/pattern/patterns.ts");

let sdk;
let modelId;
try {
  const pattern = samplePatterns.find((p) => p.id === patternId);
  if (!pattern) throw new Error(`No sample pattern with id ${patternId}`);
  await runtime.configureLocalQvac(appDirectory);
  sdk = await import("@qvac/sdk");
  modelId = await runtime.loadProposalModel(sdk, (pct) => process.stderr.write(`Downloading ${pct.toFixed(0)}%\n`));
  const startedAt = Date.now();
  const raw = await runtime.completeText(sdk, modelId, buildProposalHistory(pattern.examples));
  let candidate = null;
  let parseError = null;
  try {
    candidate = extractProposal(raw);
  } catch (error) {
    parseError = error instanceof Error ? error.message : String(error);
  }
  process.stdout.write(
    `${JSON.stringify(
      { kind: "proposed-weave", patternId, model: runtime.PROPOSAL_MODEL, raw, candidate, parseError, elapsedMs: Date.now() - startedAt },
      null,
      2,
    )}\n`,
  );
} catch (error) {
  process.stderr.write(`QVAC proposal smoke failed: ${error instanceof Error ? error.message : String(error)}\n`);
  process.exitCode = 1;
} finally {
  if (sdk && modelId) await sdk.unloadModel({ modelId, clearStorage: false }).catch(() => undefined);
  if (sdk) await sdk.close().catch(() => undefined);
}
```

<Accordion title="qvac-service/qvac-runtime.ts">

```typescript
import { mkdir, writeFile } from "node:fs/promises";
import path from "node:path";

import type { ChatMessage } from "./proposal.ts";

export const PROPOSAL_MODEL = "LLAMA_3_2_1B_INST_Q4_0";

export function resolveLocalQvacPaths(appDirectory: string) {
  const qvacDirectory = path.join(appDirectory, ".qvac");
  return {
    qvacDirectory,
    cacheDirectory: path.join(qvacDirectory, "models"),
    configPath: path.join(qvacDirectory, "config.json"),
  };
}

// Point the SDK at an app-local cache before @qvac/sdk is imported.
export async function configureLocalQvac(appDirectory: string) {
  const paths = resolveLocalQvacPaths(appDirectory);
  await mkdir(paths.cacheDirectory, { recursive: true });
  await writeFile(paths.configPath, `${JSON.stringify({ cacheDirectory: paths.cacheDirectory }, null, 2)}\n`, "utf8");
  process.env.QVAC_CONFIG_PATH = paths.configPath;
  return paths;
}

type Sdk = typeof import("@qvac/sdk");

export async function loadProposalModel(sdk: Sdk, onProgress?: (percentage: number) => void) {
  return sdk.loadModel({
    modelSrc: sdk.LLAMA_3_2_1B_INST_Q4_0,
    modelType: "llm",
    onProgress: onProgress ? (p) => onProgress(p.percentage) : undefined,
  });
}

export async function completeText(sdk: Sdk, modelId: string, history: ChatMessage[]): Promise<string> {
  const run = sdk.completion({ modelId, history, stream: true });
  let raw = "";
  for await (const token of run.tokenStream) raw += token;
  return raw;
}
```
