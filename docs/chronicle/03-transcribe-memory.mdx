We will record a short spoken memory and turn it into text with a local Whisper model.
The result is a proposed memory draft, never a saved memory.

Families often remember out loud.
A transcript keeps that context.
It can also mishear names, so a person checks it before anything enters the archive.

## Build and observe

### 1. Record your own memory

We do not ship a voice recording.
Record about ten seconds with any recorder and save it as WAV or MP3.
Read this fictional line:

> We took the night train north and played cards until the conductor came.

Keep the file outside the repository, or add it to `.gitignore`.
A voice is personal data.

### 2. Run the transcription

```bash
npm run qvac:transcribe-smoke -- ~/Downloads/my-memory.wav
```

The first run downloads the Whisper model.
Read `transcript` and `segments`.
Each segment has `startMs` and `endMs`.
Check whether the model heard the words you said.

### 3. Read the lifecycle

The script uses the same order as Chapter 2: config, then import, then `loadModel`, `transcribe`, `unloadModel`, and `close`.
`metadata: true` makes `transcribe` return segments instead of one string.
We keep the segments so a person can find where a word was said.

### 4. See why silence is an error

Open `qvac-service/transcript.ts`.
`buildMemoryDraft` throws `No speech was recognised in this recording` when every segment is empty.
It never invents text to fill a draft.
The draft always has `status: "proposed"`.

<Accordion title="qvac-service/transcribe-memory-smoke.mjs">

```javascript
import { createHash } from "node:crypto";
import { access, mkdir, readFile, writeFile } from "node:fs/promises";
import path from "node:path";
import { fileURLToPath } from "node:url";

const appDirectory = fileURLToPath(new URL("../", import.meta.url));
if (!process.argv[2]) {
  process.stderr.write(
    "Usage: npm run qvac:transcribe-smoke -- <path-to-your-recording.wav>\n",
  );
  process.exit(1);
}
const sourcePath = path.resolve(process.argv[2]);
const sourceName = path.basename(sourcePath);
const qvacDirectory = path.join(appDirectory, ".qvac");
const cacheDirectory = path.join(qvacDirectory, "models");
const configPath = path.join(qvacDirectory, "config.json");
const modelName = "WHISPER_TINY";

let modelId;
let sdk;
try {
  await access(sourcePath);
  const sourceBytes = await readFile(sourcePath);
  const sourceDigest = createHash("sha256").update(sourceBytes).digest("hex");
  await mkdir(cacheDirectory, { recursive: true });
  await writeFile(
    configPath,
    `${JSON.stringify({ cacheDirectory }, null, 2)}\n`,
    "utf8",
  );
  process.env.QVAC_CONFIG_PATH = configPath;

  sdk = await import("@qvac/sdk");
  modelId = await sdk.loadModel({
    modelSrc: sdk.WHISPER_TINY,
    modelConfig: { language: "en", translate: false, temperature: 0.0 },
    onProgress: (p) => {
      process.stderr.write(`Downloading ${p.percentage.toFixed(0)}%\n`);
    },
  });
  const segments = await sdk.transcribe({
    modelId,
    audioChunk: sourcePath,
    metadata: true,
  });
  const transcript = segments
    .map((segment) => segment.text.trim())
    .filter(Boolean)
    .join(" ")
    .replace(/\s+/g, " ")
    .trim();
  if (!transcript) throw new Error("No speech was recognised in this recording");
  process.stdout.write(
    `${JSON.stringify(
      {
        kind: "proposed-memory",
        sourceName,
        sourceDigest,
        model: modelName,
        transcript,
        segments,
      },
      null,
      2,
    )}\n`,
  );
} catch (error) {
  const message = error instanceof Error ? error.message : String(error);
  process.stderr.write(`QVAC transcribe smoke failed: ${message}\n`);
  process.exitCode = 1;
} finally {
  if (sdk && modelId) {
    await sdk.unloadModel({ modelId, clearStorage: false }).catch(() => undefined);
  }
  if (sdk) await sdk.close().catch(() => undefined);
}
```

<Accordion title="qvac-service/transcript.ts">

```typescript
export type TranscriptSegment = {
  text: string;
  startMs: number;
  endMs: number;
};

export type MemoryDraft = {
  status: "proposed";
  transcript: string;
  durationMs: number;
  sourceName: string;
  sourceDigest: string;
  model: string;
};

// Whisper segments can carry leading spaces and empty pieces.
export function joinSegments(segments: TranscriptSegment[]): string {
  return segments
    .map((segment) => segment.text.trim())
    .filter((text) => text.length > 0)
    .join(" ")
    .replace(/\s+/g, " ")
    .trim();
}

// A transcript only proposes a memory. A person still titles and saves it.
export function buildMemoryDraft(input: {
  segments: TranscriptSegment[];
  sourceName: string;
  sourceDigest: string;
  model: string;
}): MemoryDraft {
  const transcript = joinSegments(input.segments);
  if (transcript.length === 0) {
    throw new Error("No speech was recognised in this recording");
  }
  const durationMs = Math.max(0, ...input.segments.map((segment) => segment.endMs));
  return {
    status: "proposed",
    transcript,
    durationMs,
    sourceName: input.sourceName,
    sourceDigest: input.sourceDigest,
    model: input.model,
  };
}
```

```typescript
import { describe, expect, it } from "vitest";

import { buildMemoryDraft, joinSegments } from "./transcript";

// Fixture segments written by hand for this test. They are not model output.
const fixtureSegments = [
  { text: " We took the night train north", startMs: 0, endMs: 2100 },
  { text: "", startMs: 2100, endMs: 2300 },
  { text: " and played cards until the conductor came. ", startMs: 2300, endMs: 5200 },
];

describe("transcript segments", () => {
  it("joins segment text into one clean sentence", () => {
    expect(joinSegments(fixtureSegments)).toBe(
      "We took the night train north and played cards until the conductor came.",
    );
  });

  it("creates a proposed memory draft, never a saved memory", () => {
    const draft = buildMemoryDraft({
      segments: fixtureSegments,
      sourceName: "my-memory.wav",
      sourceDigest: "abc",
      model: "WHISPER_TINY",
    });
    expect(draft.status).toBe("proposed");
    expect(draft.durationMs).toBe(5200);
  });

  it("refuses silence instead of inventing a memory", () => {
    expect(() =>
      buildMemoryDraft({
        segments: [{ text: "  ", startMs: 0, endMs: 900 }],
        sourceName: "silence.wav",
        sourceDigest: "abc",
        model: "WHISPER_TINY",
      }),
    ).toThrow("No speech");
  });
});
```
