We will connect caption drafting to the Chronicle page through a small local HTTP service. A person picks memories, asks for drafts, edits or rejects each one, and then publishes an issue.

React never imports QVAC. The browser talks to a service on `127.0.0.1`. If that service is down, Chronicle still works by hand.

**Source checkpoint:** `e503d4b` · **Starting checkpoint:** `d413c3a`

## What you change

| File | Change |
| --- | --- |
| `qvac-service/server.ts` | Loopback HTTP service: `/health` and `/caption`, origin check, request check, injected drafter |
| `qvac-service/serve.mjs` | Loads the model and starts the service on port 4318 |

| `src/features/chronicle/issue.ts` | Publish only when every selected draft is resolved |

## Build and observe

### 1. Start the app without the service

```bash
npm run dev
```

Tick "Include in issue" on "First tomatoes" and select **Publish issue**. The issue appears. Now select **Draft caption for Nine candles**. You see "The local QVAC service is not running. You can still edit captions by hand." That is the correct result.

### 2. Start the service

In a second terminal:

```bash
npm run qvac:service
curl http://127.0.0.1:4318/health
```

`drafting: true` means the model loaded. `drafting: false` means the process is up but the model is not. Then `/caption` answers 503, never a made-up caption.

### 3. Review a draft

Tick "Picnic at Gull Point" and draft its caption. Try **Publish issue** first. It is blocked: "Accept or reject every caption draft before publishing". Edit the draft, select **Accept caption**, and publish. The issue shows your edited text. Caption history shows the old caption.

### 4. Inspect the boundary

The service binds to `127.0.0.1` and only admits browser origins on `localhost` or `127.0.0.1`. It checks the memory before calling the model and checks the draft before returning it. The client checks again, including that the draft is for the memory it asked about. This keeps out other websites. It is not protection against other software on your own machine.

```typescript
import { createServer, type IncomingMessage, type ServerResponse } from "node:http";

import type { Memory } from "../src/features/chronicle/archive";

export const SERVICE_PORT = 4318;
const MAX_BODY_BYTES = 16_384;

export type CaptionDrafter = (memory: Memory) => Promise<{ draft: string; model: string }>;

export function isAllowedOrigin(origin: string | undefined): boolean {
  if (!origin) return true; // curl and other local tools send no Origin
  try {
    const url = new URL(origin);
    return (
      url.protocol === "http:" &&
      (url.hostname === "localhost" || url.hostname === "127.0.0.1")
    );
  } catch {
    return false;
  }
}

export function parseMemory(value: unknown): Memory {
  const v = value as Partial<Memory> | null;
  if (
    !v ||
    typeof v.id !== "string" ||
    typeof v.title !== "string" ||
    typeof v.date !== "string" ||
    typeof v.caption !== "string" ||
    !Array.isArray(v.people) ||
    !v.people.every((p) => typeof p === "string")
  ) {
    throw new Error("Request must contain one memory");
  }
  return {
    id: v.id,
    title: v.title,
    date: v.date,
    people: v.people,
    caption: v.caption,
    photo: typeof v.photo === "string" ? v.photo : null,
  };
}

function send(res: ServerResponse, status: number, body: unknown, origin?: string) {
  res.writeHead(status, {
    "content-type": "application/json",
    ...(origin ? { "access-control-allow-origin": origin, vary: "Origin" } : {}),
    "access-control-allow-headers": "content-type",
    "access-control-allow-methods": "GET, POST, OPTIONS",
  });
  res.end(JSON.stringify(body));
}

async function readJson(req: IncomingMessage): Promise<unknown> {
  let size = 0;
  const chunks: Buffer[] = [];
  for await (const chunk of req) {
    size += (chunk as Buffer).length;
    if (size > MAX_BODY_BYTES) throw new Error("Request is too large");
    chunks.push(chunk as Buffer);
  }
  return JSON.parse(Buffer.concat(chunks).toString("utf8"));
}

// The service drafts. It never saves anything. The browser decides.
export function createCaptionServer(options: { drafter: CaptionDrafter | null }) {
  return createServer(async (req, res) => {
    const origin = req.headers.origin;
    if (!isAllowedOrigin(origin)) return send(res, 403, { error: "Origin not allowed" });
    if (req.method === "OPTIONS") return send(res, 204, null, origin);
    if (req.method === "GET" && req.url === "/health") {
      return send(res, 200, { ok: true, drafting: options.drafter !== null }, origin);
    }
    if (req.method !== "POST" || req.url !== "/caption") {
      return send(res, 404, { error: "Not found" }, origin);
    }
    let memory: Memory;
    try {
      memory = parseMemory(await readJson(req));
    } catch (error) {
      return send(res, 400, { error: (error as Error).message }, origin);
    }
    if (!options.drafter) {
      return send(res, 503, { error: "Caption drafting is not available" }, origin);
    }
    try {
      const result = await options.drafter(memory);
      return send(res, 200, { memoryId: memory.id, ...result }, origin);
    } catch (error) {
      return send(res, 502, { error: (error as Error).message }, origin);
    }
  });
}
```

<Accordion title="qvac-service/serve.mjs">

```javascript
import { mkdir, writeFile } from "node:fs/promises";
import path from "node:path";
import { fileURLToPath } from "node:url";

const appDirectory = fileURLToPath(new URL("../", import.meta.url));
const qvacDirectory = path.join(appDirectory, ".qvac");
const cacheDirectory = path.join(qvacDirectory, "models");
const configPath = path.join(qvacDirectory, "config.json");

const { createCaptionServer, SERVICE_PORT } = await import("./server.ts");
const { buildCaptionHistory, parseCaptionDraft } = await import("./caption-draft.ts");

await mkdir(cacheDirectory, { recursive: true });
await writeFile(configPath, `${JSON.stringify({ cacheDirectory }, null, 2)}\n`, "utf8");
process.env.QVAC_CONFIG_PATH = configPath;

let sdk;
let modelId;
let drafter = null;
try {
  sdk = await import("@qvac/sdk");
  modelId = await sdk.loadModel({ modelSrc: sdk.LLAMA_3_2_1B_INST_Q4_0, modelType: "llm" });
  drafter = async (memory) => {
    const run = sdk.completion({ modelId, history: buildCaptionHistory({ memory }), stream: true });
    let raw = "";
    for await (const token of run.tokenStream) raw += token;
    return { draft: parseCaptionDraft(raw), model: "LLAMA_3_2_1B_INST_Q4_0" };
  };
} catch (error) {
  process.stderr.write(
    `Caption model unavailable: ${error instanceof Error ? error.message : String(error)}\n` +
      "The service will answer 503 and Chronicle keeps working manually.\n",
  );
}

const server = createCaptionServer({ drafter });
server.listen(SERVICE_PORT, "127.0.0.1", () => {
  process.stderr.write(`Chronicle QVAC service on http://127.0.0.1:${SERVICE_PORT}\n`);
});

async function shutdown() {
  server.close();
  if (sdk && modelId) await sdk.unloadModel({ modelId, clearStorage: false }).catch(() => undefined);
  if (sdk) await sdk.close().catch(() => undefined);
  process.exit(0);
}
process.on("SIGINT", shutdown);
process.on("SIGTERM", shutdown);
```

```typescript
import type { Memory } from "./archive";

export const CAPTION_SERVICE_URL = "http://127.0.0.1:4318";

export type DraftResult =
  | { ok: true; memoryId: string; draft: string; model: string }
  | { ok: false; error: string };

export type RequestDraft = (memory: Memory) => Promise<DraftResult>;

export function parseDraftResponse(memoryId: string, status: number, body: unknown): DraftResult {
  const v = body as { memoryId?: unknown; draft?: unknown; model?: unknown; error?: unknown } | null;
  if (status !== 200) {
    return { ok: false, error: typeof v?.error === "string" ? v.error : `Service answered ${status}` };
  }
  if (
    !v ||
    v.memoryId !== memoryId ||
    typeof v.draft !== "string" ||
    v.draft.trim().length === 0 ||
    typeof v.model !== "string"
  ) {
    return { ok: false, error: "The service returned an invalid draft" };
  }
  return { ok: true, memoryId, draft: v.draft, model: v.model };
}

export const requestDraft: RequestDraft = async (memory) => {
  try {
    const res = await fetch(`${CAPTION_SERVICE_URL}/caption`, {
      method: "POST",
      headers: { "content-type": "application/json" },
      body: JSON.stringify(memory),
    });
    return parseDraftResponse(memory.id, res.status, await res.json().catch(() => null));
  } catch {
    return { ok: false, error: "The local QVAC service is not running" };
  }
};
```

<Accordion title="src/features/chronicle/issue.ts">

```typescript
import type { Memory } from "./archive";
import type { CaptionProposal } from "./caption-review";

export type PublishedIssue = {
  title: string;
  publishedAt: string;
  spreads: { memoryId: string; title: string; caption: string }[];
};

export function publishIssue(input: {
  title: string;
  memories: Memory[];
  selectedIds: string[];
  proposals: CaptionProposal[];
  at: string;
}): PublishedIssue {
  if (input.title.trim().length === 0) throw new Error("Give the issue a title");
  if (input.selectedIds.length === 0) throw new Error("Choose at least one memory");
  const unresolved = input.proposals.filter(
    (p) => p.status === "proposed" && input.selectedIds.includes(p.memoryId),
  );
  if (unresolved.length > 0) {
    throw new Error("Accept or reject every caption draft before publishing");
  }
  return {
    title: input.title.trim(),
    publishedAt: input.at,
    spreads: input.memories
      .filter((m) => input.selectedIds.includes(m.id))
      .map((m) => ({ memoryId: m.id, title: m.title, caption: m.caption })),
  };
}
```

<Accordion title="src/features/chronicle/IssueEditor.tsx">

```tsx
"use client";

import { useState } from "react";

import { memoriesByDate, type Memory } from "./archive";
import { requestDraft as defaultRequestDraft, type RequestDraft } from "./caption-client";
import {
  acceptCaption,
  proposeCaption,
  rejectCaption,
  type CaptionProposal,
  type CaptionRevision,
} from "./caption-review";
import { publishIssue, type PublishedIssue } from "./issue";

export function IssueEditor(props: {
  initialMemories: Memory[];
  requestDraft?: RequestDraft;
  now?: () => string;
}) {
  const requestDraft = props.requestDraft ?? defaultRequestDraft;
  const now = props.now ?? (() => new Date().toISOString());
  const [memories, setMemories] = useState(() => memoriesByDate(props.initialMemories));
  const [selected, setSelected] = useState<string[]>([]);
  const [proposals, setProposals] = useState<CaptionProposal[]>([]);
  const [edits, setEdits] = useState<Record<string, string>>({});
  const [revisions, setRevisions] = useState<CaptionRevision[]>([]);
  const [pending, setPending] = useState<string | null>(null);
  const [notice, setNotice] = useState<string | null>(null);
  const [issueTitle, setIssueTitle] = useState("Summer issue");
  const [issue, setIssue] = useState<PublishedIssue | null>(null);

  const openProposal = (id: string) =>
    proposals.find((p) => p.memoryId === id && p.status === "proposed");

  async function draft(memory: Memory) {
    setPending(memory.id);
    setNotice(null);
    const result = await requestDraft(memory);
    setPending(null);
    if (!result.ok) {
      setNotice(`${result.error}. You can still edit captions by hand.`);
      return;
    }
    setProposals((all) => [
      ...all.filter((p) => !(p.memoryId === memory.id && p.status === "proposed")),
      proposeCaption(memory.id, result.draft),
    ]);
    setEdits((all) => ({ ...all, [memory.id]: result.draft }));
  }

  function accept(memory: Memory, proposal: CaptionProposal) {
    const result = acceptCaption(memory, proposal, edits[memory.id] ?? proposal.draft, now());
    setMemories((all) => all.map((m) => (m.id === memory.id ? result.memory : m)));
    setProposals((all) => all.map((p) => (p === proposal ? result.proposal : p)));
    setRevisions((all) => [result.revision, ...all]);
  }

  function reject(proposal: CaptionProposal) {
    setProposals((all) => all.map((p) => (p === proposal ? rejectCaption(proposal) : p)));
  }

  function publish() {
    try {
      setIssue(publishIssue({ title: issueTitle, memories, selectedIds: selected, proposals, at: now() }));
      setNotice(null);
    } catch (error) {
      setNotice((error as Error).message);
    }
  }

  return (
    <section aria-label="Issue editor">
      <label>
        Issue title{" "}
        <input value={issueTitle} onChange={(e) => setIssueTitle(e.target.value)} />
      </label>
      {notice && <p role="status">{notice}</p>}
      <ol aria-label="Archive">
        {memories.map((memory) => {
          const proposal = openProposal(memory.id);
          return (
            <li key={memory.id}>
              <h2>{memory.title}</h2>
              <p>
                <time dateTime={memory.date}>{memory.date}</time> · {memory.people.join(", ")}
              </p>
              <p>{memory.caption}</p>
              <label>
                <input
                  type="checkbox"
                  checked={selected.includes(memory.id)}
                  onChange={(e) =>
                    setSelected((all) =>
                      e.target.checked ? [...all, memory.id] : all.filter((id) => id !== memory.id),
                    )
                  }
                />{" "}
                Include in issue
              </label>{" "}
              <button type="button" disabled={pending !== null} onClick={() => draft(memory)}>
                {pending === memory.id ? "Drafting…" : `Draft caption for ${memory.title}`}
              </button>
              {proposal && (
                <div aria-label={`Proposed caption for ${memory.title}`}>
                  <p>Proposed by a local model. Edit it before you accept.</p>
                  <textarea
                    aria-label={`Edit draft for ${memory.title}`}
                    value={edits[memory.id] ?? proposal.draft}
                    onChange={(e) => setEdits((all) => ({ ...all, [memory.id]: e.target.value }))}
                  />
                  <button type="button" onClick={() => accept(memory, proposal)}>
                    Accept caption
                  </button>{" "}
                  <button type="button" onClick={() => reject(proposal)}>
                    Reject draft
                  </button>
                </div>
              )}
            </li>
          );
        })}
      </ol>
      <button type="button" onClick={publish}>
        Publish issue
      </button>
      {issue && (
        <article aria-label="Published issue">
          <h2>{issue.title}</h2>
          <ul>
            {issue.spreads.map((s) => (
              <li key={s.memoryId}>
                {s.title}: {s.caption}
              </li>
            ))}
          </ul>
        </article>
      )}
      {revisions.length > 0 && (
        <ul aria-label="Caption history">
          {revisions.map((r) => (
            <li key={`${r.memoryId}-${r.at}`}>
              {r.memoryId}: “{r.previous}” → “{r.next}”
            </li>
          ))}
        </ul>
      )}
    </section>
  );
}
```
