Home records scatter across binders, email, drives, and memory, and only become urgent after something breaks.

**QVAC capabilities:** OCR · Multimodal · RAG · Text generation

## Before and after

| | |
|---|---|
| **Without AI** | Register the water heater and file its manual by hand. |
| **With QVAC** | Photograph a label and a receipt, accept the extracted details, then ask a question whose answer links to the exact manual page and service record. |
