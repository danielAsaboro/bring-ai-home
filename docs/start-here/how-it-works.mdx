Bring AI Home teaches local AI the way you will use it at work: inside a real product.
Every project is a complete application that already does its job without a model.
You then add QVAC one capability at a time.

## The learning loop

Each lesson follows the same five steps:

1. Start from the previous checkpoint and reproduce the limitation.
2. Look at the symptom before we explain its cause.
3. Find the layer that is actually wrong: model lifecycle, transport, geometry, reasoning, state, resilience, evaluation, or network.
4. Apply only the change that fixes it.
5. Run the smallest test that proves it, then see it in the product.

We never fake a model mistake and present it as live output.
Timing-dependent and malformed-output cases use checked-in tests, so you can reproduce them exactly.

## One rule across every project

A model **proposes**.
Your application **decides** what becomes permanent.
A person **approves** anything that matters.
OCR becomes evidence, not a redaction.
A parsed receipt becomes a draft transaction, not a balance.
