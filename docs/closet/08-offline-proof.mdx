Saying "it runs locally" is a claim. A blocked `fetch` in the browser or a non-empty cache folder does not prove it. We deny outbound network for the whole Node process, check that a real probe is refused, and then run Closet's model features from the cache.

## Build and observe

### 1. Warm the cache online

Run the service once with normal internet and use each feature (photo, search, outfit) so every model downloads into `.qvac/models`.

### 2. Check the cache before going offline

`assertWarmedCache` requires a non-empty file for the vision model, its projection model, the 1B language model, and the embedding model. A missing one fails before any network question is asked. On our build container, where model downloads are blocked, it printed:

```text
Offline proof failed: QVAC cache is incomplete (vision, projection, details, embeddings). Warm it online with qvac:service and one run of each feature first.
```

That is the expected failure on a cold cache. It is not an offline proof.

### 3. Run under network denial (macOS)

```bash
npm run qvac:offline
```

`sandbox-exec` applies `offline.sb` to the Node process and everything it spawns. The script first probes `https://example.com`. Only a refused connection counts as `network-denied`; a DNS failure is reported as `dns-failed`, because it can mean a broken resolver rather than denial. Then it embeds the sample looks for `rainy work day` and validates an outfit proposal, printing both.

On Linux, `sandbox-exec` does not exist. A network namespace (for example `unshare`) can deny the process network, but we have not recorded a Linux receipt for this course.

### 4. Run the whole app under the same policy

```bash
npm run qvac:service:offline
npm run dev
```

The service still listens on loopback, which the profile allows. Add a garment from a photo, search the feed, and propose a carousel. Every proposal still goes through the same review.

<Accordion title="qvac-service/offline-proof.ts">

```typescript
// Each pattern must match at least one non-empty file in the model cache.
export const REQUIRED_MODELS: Record<string, RegExp> = {
  vision: /smolvlm2/i,
  projection: /mmproj/i,
  details: /llama-3\.2-1b/i,
  embeddings: /gte-large/i,
};

export function assertWarmedCache(
  files: readonly { name: string; bytes: number }[],
  required: Record<string, RegExp> = REQUIRED_MODELS,
) {
  const missing = Object.entries(required)
    .filter(([, pattern]) => !files.some((f) => pattern.test(f.name) && f.bytes > 0))
    .map(([label]) => label);
  if (missing.length > 0) {
    throw new Error(
      `QVAC cache is incomplete (${missing.join(", ")}). Warm it online with qvac:service and one run of each feature first.`,
    );
  }
}

// Classify a probe to a reachable public host. Only a refused connection counts.
export function classifyProbe(result: { ok: true } | { ok: false; code: string | undefined }) {
  if (result.ok) return "network-allowed" as const;
  if (result.code === "ENOTFOUND" || result.code === "EAI_AGAIN") return "dns-failed" as const;
  return "network-denied" as const;
}
```

<Accordion title="qvac-service/offline-check.mjs">

```javascript
import { readdir, stat } from "node:fs/promises";
import https from "node:https";
import path from "node:path";
import { fileURLToPath } from "node:url";

const appDirectory = fileURLToPath(new URL("../", import.meta.url));
const { assertWarmedCache, classifyProbe } = await import("./offline-proof.ts");
const { resolveLocalQvacPaths } = await import("./local-config.ts");
const { createQvacEngine } = await import("./qvac-engine.ts");
const { sampleCloset } = await import("../src/features/closet/sample-closet.ts");
const { buildOutfitConstraints, validateOutfitProposal } = await import("../src/features/closet/outfit-proposal.ts");
const { lookText, rankLooks } = await import("../src/features/closet/look-search.ts");

const { cacheDirectory } = resolveLocalQvacPaths(appDirectory);
const occasion = "rainy work day";

function probe() {
  return new Promise((resolve) => {
    const req = https.get("https://example.com/", { timeout: 5000 }, (res) => {
      res.resume();
      resolve({ ok: true });
    });
    req.on("timeout", () => req.destroy(Object.assign(new Error("timeout"), { code: "ETIMEDOUT" })));
    req.on("error", (error) => resolve({ ok: false, code: error.code }));
  });
}

let engine;
try {
  const names = await readdir(cacheDirectory).catch(() => []);
  const files = await Promise.all(
    names.map(async (name) => ({ name, bytes: (await stat(path.join(cacheDirectory, name))).size })),
  );
  assertWarmedCache(files);

  const network = classifyProbe(await probe());
  if (network !== "network-denied") {
    throw new Error(`Expected this process to be denied network access, got ${network}`);
  }

  engine = await createQvacEngine(appDirectory);
  const closet = sampleCloset();
  const startedAt = Date.now();

  const texts = closet.looks.map((look) => lookText(look, closet.garments));
  const { embeddings } = await engine.embed([occasion, ...texts]);
  const [queryVector, ...lookVectors] = embeddings;
  const looks = rankLooks(closet.looks.map((l) => l.id), lookVectors, queryVector);

  const constraints = buildOutfitConstraints(closet, occasion);
  const { raw, model } = await engine.outfit(constraints);
  const outfit = validateOutfitProposal(raw, constraints);

  process.stdout.write(
    `${JSON.stringify({ network, occasion, looks, outfit: { model, ...outfit }, elapsedMs: Date.now() - startedAt }, null, 2)}\n`,
  );
} catch (error) {
  process.stderr.write(`Offline proof failed: ${error instanceof Error ? error.message : String(error)}\n`);
  process.exitCode = 1;
} finally {
  if (engine) await engine.close();
}
```

```typescript
import { describe, expect, it } from "vitest";

import { assertWarmedCache, classifyProbe } from "./offline-proof";

// File names below are fixtures shaped like cache entries, not a real cache listing.
describe("offline proof", () => {
  it("refuses to start when a model is missing or empty", () => {
    expect(() =>
      assertWarmedCache([
        { name: "SmolVLM2-500M-Video-Instruct-Q8_0.gguf", bytes: 10 },
        { name: "mmproj-SmolVLM2-500M-Video-Instruct-Q8_0.gguf", bytes: 10 },
        { name: "Llama-3.2-1B-Instruct-Q4_0.gguf", bytes: 0 },
      ]),
    ).toThrow("incomplete (details, embeddings)");
  });

  it("accepts a fully warmed cache", () => {
    expect(() =>
      assertWarmedCache([
        { name: "SmolVLM2-500M-Video-Instruct-Q8_0.gguf", bytes: 10 },
        { name: "mmproj-SmolVLM2-500M-Video-Instruct-Q8_0.gguf", bytes: 10 },
        { name: "Llama-3.2-1B-Instruct-Q4_0.gguf", bytes: 10 },
        { name: "gte-large_fp16.gguf", bytes: 10 },
      ]),
    ).not.toThrow();
  });

  it("only counts a refused connection as network denial", () => {
    expect(classifyProbe({ ok: true })).toBe("network-allowed");
    expect(classifyProbe({ ok: false, code: "ENOTFOUND" })).toBe("dns-failed");
    expect(classifyProbe({ ok: false, code: "EPERM" })).toBe("network-denied");
  });
});
```
