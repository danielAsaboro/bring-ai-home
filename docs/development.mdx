title: "Preview and edit the docs"
description: "Run this Mintlify site locally and add a page to its navigation."
---

## Start the preview

Install a current Node.js release and the Mintlify CLI if they are not already available:

```bash
npm install -g mint
```

Run the preview from the repository root:

```bash
mint dev --port 3333
```

Open `http://localhost:3333`. The preview reloads when you save a page.

## Add a page

1. Create an `.mdx` file in the repository.
2. Add a title and description in YAML frontmatter.
3. Write the page body below the frontmatter.
4. Add the file's path, without `.mdx`, to a group in `docs.json`.

For example, `articles/first-post.mdx` is registered as `articles/first-post`.

## Validate changes

Run these commands from the repository root:

```bash
mint validate
mint broken-links
```

## Publish with Mintlify

Connect the documentation repository in your Mintlify dashboard. The site lives at the repository root, so no documentation directory is needed. Confirm the branch and deployment settings before publishing.

See the [Mintlify quickstart](https://mintlify.com/docs/quickstart) for the hosted setup.
