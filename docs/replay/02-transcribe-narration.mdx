Writing frames by hand is the slow part. The fastest way to describe a job is to do it once and talk while you do it.

Before we touch the app, we prove transcription works on its own. If something fails here, it is a download, a native runtime, or an audio file problem, never React.

**Source checkpoint:** `986f94b` · **Starting checkpoint:** `4e275a0`

## What changes

- `package.json`: adds `@qvac/sdk` pinned to `0.22.0`, `b4a` as a direct dependency, and `npm run qvac:transcribe-smoke`.
- `qvac-service/transcribe-smoke.mjs`: loads `WHISPER_TINY`, transcribes one `.wav` with `metadata: true`, prints JSON.
- `src/features/replay/narration.ts`: drops silence tags such as `[BLANK_AUDIO]`, trims, sorts, and refuses a recording with no speech.
- `src/features/replay/fixtures/narration.fixture.ts`: hand-written segments, labelled as a fixture, so tests are identical on every machine.

## Build and observe

### 1. Install the pinned SDK

```bash
git checkout 986f94b
npm ci
```

On Linux, the bare runtime binary may need the executable bit:

```bash
chmod +x node_modules/bare-runtime-linux-x64/bin/bare
```

### 2. Record a narration

Record yourself doing the weekly report job, about twenty seconds, as a 16 kHz mono `.wav`. Say the steps out loud, including one value that changes each week and one moment when you would stop. For example: "If the export comes back empty, I stop and ask in the ops channel."

Use your own voice. The course does not ship a recording, and the tests never pretend one exists.

### 3. Run the smoke script

```bash
npm run qvac:transcribe-smoke -- ~/Desktop/weekly-report.wav
```

The first run downloads `WHISPER_TINY` into `.qvac/models`. Later runs reuse that cache. The output is a JSON object with `kind: "narration-evidence"`, the SHA-256 of the file, timings, the joined transcript, and each segment's `startMs` and `endMs`.

### 4. Read the transcript as evidence

The transcript is what the model heard. It is not a step. Some words will be wrong. Every later chapter checks model output against this text instead of trusting it.

If the script prints `No speech was recognised`, the recording was silent or the format was wrong. That is an input problem, not a model problem.

```javascript
// Standalone smoke test: one narrated recording in, one transcript out.
// Runs outside Next.js so download, native runtime, and React problems stay separate.
import { createHash } from "node:crypto";
import { access, mkdir, readFile, writeFile } from "node:fs/promises";
import path from "node:path";
import { fileURLToPath } from "node:url";

const appDirectory = fileURLToPath(new URL("../", import.meta.url));
if (!process.argv[2]) {
  process.stderr.write("Usage: npm run qvac:transcribe-smoke -- <your-narration.wav>\n");
  process.exit(1);
}
const sourcePath = path.resolve(process.argv[2]);
const qvacDirectory = path.join(appDirectory, ".qvac");
const cacheDirectory = path.join(qvacDirectory, "models");
const configPath = path.join(qvacDirectory, "config.json");

const { toNarration } = await import("../src/features/replay/narration.ts");

let sdk;
let modelId;
try {
  await access(sourcePath);
  const sourceDigest = createHash("sha256").update(await readFile(sourcePath)).digest("hex");
  await mkdir(cacheDirectory, { recursive: true });
  await writeFile(configPath, `${JSON.stringify({ cacheDirectory }, null, 2)}\n`, "utf8");
  process.env.QVAC_CONFIG_PATH = configPath;

  sdk = await import("@qvac/sdk");
  const loadStarted = Date.now();
  modelId = await sdk.loadModel({
    modelSrc: sdk.WHISPER_TINY,
    modelConfig: { language: "en", translate: false, temperature: 0.0 },
    onProgress: (p) => process.stderr.write(`Downloading ${p.percentage.toFixed(0)}%\n`),
  });
  const loadMs = Date.now() - loadStarted;
  const started = Date.now();
  const segments = await sdk.transcribe({ modelId, audioChunk: sourcePath, metadata: true });
  const narration = toNarration(segments);
  process.stdout.write(
    `${JSON.stringify(
      {
        kind: "narration-evidence",
        sourceName: path.basename(sourcePath),
        sourceDigest,
        model: "WHISPER_TINY",
        loadMs,
        transcribeMs: Date.now() - started,
        ...narration,
      },
      null,
      2,
    )}\n`,
  );
} catch (error) {
  const message = error instanceof Error ? error.message : String(error);
  process.stderr.write(
    `QVAC transcribe smoke failed: ${message}\nThe first run downloads WHISPER_TINY into ${cacheDirectory}.\n`,
  );
  process.exitCode = 1;
} finally {
  if (sdk && modelId) await sdk.unloadModel({ modelId, clearStorage: false }).catch(() => undefined);
  if (sdk) await sdk.close().catch(() => undefined);
}
```

<Accordion title="src/features/replay/narration.ts">

```typescript
// Turns raw transcription segments into a reviewable narration.
// The transcript is evidence of what was said. It is never a step by itself.

export type NarrationSegment = { text: string; startMs: number; endMs: number };

export type Narration = {
  transcript: string;
  segments: NarrationSegment[];
  durationMs: number;
};

export function toNarration(raw: readonly NarrationSegment[]): Narration {
  const segments = raw
    .map((s) => ({ text: s.text.replace(/\s+/g, " ").trim(), startMs: s.startMs, endMs: s.endMs }))
    .filter((s) => s.text.length > 0 && Number.isFinite(s.startMs) && Number.isFinite(s.endMs))
    // Whisper marks silence and noise with bracketed tags such as [BLANK_AUDIO].
    .filter((s) => !/^\[[A-Z_ ]+\]$/.test(s.text))
    .sort((a, b) => a.startMs - b.startMs);
  if (segments.length === 0) throw new Error("No speech was recognised in this recording");
  return {
    transcript: segments.map((s) => s.text).join(" "),
    segments,
    durationMs: Math.max(...segments.map((s) => s.endMs)),
  };
}

export function formatTimestamp(ms: number) {
  const total = Math.max(0, Math.floor(ms / 1000));
  return `${Math.floor(total / 60)}:${String(total % 60).padStart(2, "0")}`;
}
```
