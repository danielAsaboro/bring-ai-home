How a lesson goes

Every lesson breaks something first.

You start each project with an app that already works without AI. Then you add one QVAC capability at a time, and you watch it fail before you fix it.

  1. Break it

    Start from the last checkpoint and reproduce the limitation on a real machine. Rotate the page, stop the service, pull the network.

  2. Find the layer

    Is it the model, the transport, the geometry, the state or the network? Most AI bugs aren't in the AI.

  3. Change only that

    One tested commit per lesson, with a patch you can apply and a written walkthrough of every file it touches.

  4. Prove it

    Every lesson ends with a receipt: the smallest test or measurement that shows it worked, so you never have to take my word for it.
